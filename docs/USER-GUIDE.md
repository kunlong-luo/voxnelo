# Voxnelo 用户帮助（公开版 v1.0.3；v1.0.4 尚未发布）

Voxnelo 是一款免费、本地优先的英语口语练习桌面应用，无需注册即可开始使用。**这是公开发行的免签名桌面版，系统安全限制和跨平台验证边界仍需注意。** 维护者：Leo Luo。

## 安装与升级

到 [GitHub Releases v1.0.3](https://github.com/kunlong-luo/voxnelo/releases/tag/v1.0.3) 下载适合系统的安装包，优先检查发布页的 SHA-256 校验文件：

- **Linux x64**：Debian、Ubuntu、Pop!_OS 推荐 `Voxnelo.deb`（与 `voxnelo_1.0.3_amd64.deb` 相同）；其他兼容系统可尝试 `.AppImage`。升级通常不需卸载旧版。DEB 会通过包管理器安装所需系统依赖。
- **Windows**：下载 NSIS `.exe` 并正常安装。安装包暂未进行数字签名；SmartScreen 警告要如实对待并先确认来源，不要将其当成经认证的稳定应用。
- **macOS**：下载 `.dmg`，核对 DMG 架构兼容性，按系统流程安装。安装器未签名、未公证，Gatekeeper 可能阻止打开；若不愿接受此限制，请暂不安装这一免签名正式版。

**普通桌面安装无需开发工具链。** 使用上述安装包即可开始学习，不需要安装 Node.js、pnpm 或其他 JavaScript 包管理器。离线模型的用户主动安装仍遵循对应平台的 Python / 模型要求；源码开发者另见 [开发指南](DEVELOPMENT.md)。

## 第一条英语练习

1. 打开「练习」，选择一条短句，点击播放示范（取决于系统英语 TTS 语音包）。
2. 点击录音按钮、授权麦克风、说英语，再次点击停止后即可回听。等待系统权限授权时，可以点击同一录音按钮「取消录音授权请求」；此操作取消 Voxnelo 本次录音请求，不一定会关闭系统权限弹窗。取消后即使系统随后授予权限，也不会自动开始录音；如需录音，请主动重新点击。
3. 「换一句」切换短句；收藏、复习和历史保存在当前设备上。
4. 界面可切换中文/英文、Nordic/Sunset 主题、IPA 和减少动效设置。

**v1.0.4 未发布候选版新增：分段听读。** 在练习页发音指南展开「分段跟读」，选择英文片段，点击「播放所选片段」听系统英语 TTS，再使用下方录音按钮朗读并回听。它不会裁剪录音到该片段，也不会对准确率评分；文本分组不是人工语言学断句，连读规则仍是待审核教学示例。**公开 v1.0.3 不包含此新功能。**

## 当前开发源码新增：实时听写主操作与录制回听的区别（未公开发布）

**本节描述 2026-11-23 之后的 V3 界面源码，不属于已公开 v1.0.3，也不在 2026-11-23 审核通过的旧提交 `7793c383` 三平台 v1.0.4 候选安装包中。** 因此不要使用旧安装包截图来宣称新版界面已经交付。

- **实时听写（主操作）**：打开练习页，在英文短句下方点击带文字的「开始实时听写」。当设备实际进入识别过程后，按钮显示「停止听写」；当前中间识别文字优先显示，识别告一段落后显示最新完成的内容。完整历史默认收起，需要时点击「查看历史」。长段听写不会在主区域无止境累积文字。
- **录制回听（次级操作）**：下方独立的「录制回听」按钮用于录制自己的声音、手动停止并本地回听；这**不是**实时文字识别，也不代表自动评测发音。正在听写或录音时，原有的会话互斥和取消/停止行为仍然生效，避免两个麦克风流程争用。
- **模型不可用**：主区域会明确提示离线模型或识别组件不可用；「管理离线模型」和听写帮助在矮窗口也应保持可操作。离线模型仍必须在模型管理页由用户主动安装并验证，软件不会暗中回退为浏览器在线识别。
- **在线识别提示（仅浏览器可选择）**：只有用户明确切换到浏览器在线识别，才允许触发可能上传音频的模式；界面必须持续告知音频可能经由浏览器服务处理。
- **空间不足时**：空白状态提示可收起，**开始/停止、当前真实字幕、录制回听和模型修复入口不能因视觉紧凑而消失**。系统权限、降噪、字幕准确度和真人麦克风延迟仍需实机验证。

设计依据、双主题对比和验收矩阵见 [V3 Dictation-first 界面规范](design/V3-DICTATION-FIRST-UX-2026-11-23.md)。这项视觉升级不修改发布状态或已经生成的安装包 SHA-256。

## v1.0.4 候选版：间隔复习（尚未公开发布）

打开练习句子，点击书签按钮「标记需要复习」，句子立即进入「复习」页的「已到期」列表。复习页可查看「全部 / 已到期 / 稍后复习」及下次复习日期。听示范、跟读并录音完成后，系统会从实际练习日期开始安排下一次复习；如果未录音但确实已跟读，也可主动点击「我已跟读，安排下次」。间隔依次为 **1、3、7、14、30 天**，之后保持 30 天间隔。

此计划来自**用户自评与完成时间**，不是测得的口语水平。仅打开或浏览句子不会推进复习，手动点击完成也不会伪造一条录音历史或发音成绩。取消复习标记将移除安排，再次标记则从待复习开始；历史旧数据会兼容读取。这一功能不包含在公开 v1.0.3 中，完整跨平台实机/日期边界仍需验收。

## v1.0.4 候选版：本地 JSON 备份与恢复（尚未公开发布）

在「设置 → 本地学习数据备份与恢复」中点击「导出学习数据」，系统会通过本机下载机制创建 `voxnelo-learning-backup-YYYY-MM-DD.json`。包含**所有**本地浏览与已完成录音事件（不是历史列表只显示的最近 250 条）、收藏、需要复习标记、复习安排和已记录的学习状态。**不包含**麦克风录音本身、Moonshine 模型、系统音量及个人设置。JSON 未加密，请勿将备份上传到公开 Issue。

恢复步骤：点击「选择备份文件」，先核对预览中的学习状态及历史事件数量；界面会明确警告**导入会完整替换本设备现有学习数据**。建议先备份本机旧数据，然后主动点击确认标记，再按「确认恢复学习数据」。只有 Voxnelo v1 JSON、已知课程 ID、合法字段与符合安全大小限制的文件能被恢复；校验失败不修改原数据。实际导入使用单个 IndexedDB 事务，写入失败会回滚，不是合并导入。恢复后会重新读取学习状态。

安全上限为 8 MiB 文件、50,000 条历史事件和当前课程 ID 数量以内的状态；超过上限会明确报错，不会静默截断导出或导入。**此功能不在公开 v1.0.3 中，跨设备备份恢复仍需真人测试。**

## v1.0.4 候选版：已熟悉标记与筛选（尚未公开发布）

练习页短句右上方增加「标记为已熟悉（自评）」按钮；只有用户主动点击才会保存已熟悉状态。打开「收藏」页，可以通过「我的收藏 / 已熟悉」切换查看对应集合，继续按中英文搜索。已熟悉句子无需先收藏；收藏和真实浏览/录音历史仍保留。

标记已熟悉会自动退出原「需要复习」队列并清除该句待复习日期；日后重新标记「需要复习」则取消已熟悉标记并开始新的复习计划。两者不可同时激活，收藏可与任何一方并存。反复浏览或录音**不会**自动标记已熟悉，也不代表已通过发音测评。

本机旧版学习记录继续可读取，F107 既有 v1 JSON 备份仍可导入；新版备份的已熟悉标记会一并保存。**公开 v1.0.3 不包含此功能。**

## v1.0.4 候选版：独立播放音量（尚未公开发布）

在「设置 → 语音播放 → 播放音量」中选择 **0% / 25% / 50% / 75% / 100%**。0% 为静音，其他档位控制 Voxnelo 示例语音（Chromium 系统英语 TTS、Linux eSpeak 生成的 WAV）及刚录制的回听；若未来启用通过内容/授权审核的离线 WAV，亦遵循同一音量。音量只保存在本机浏览器存储中，重新打开应用仍能读取。**不会改变系统主音量、麦克风录制增益或 Moonshine 离线听写识别。**

该设置不包含在公开 v1.0.3 发行包中；真实设备的音量端到端行为仍需要手工验收。

## Linux 实时英语听写（Moonshine）

Linux x64 默认使用 Moonshine Voice Medium Streaming，**模型与 Python 运行时不会随安装包自动下载**。打开「离线模型管理」并点击「安装 Moonshine 离线识别模型」，在你主动同意后才下载官方 SDK 与模型。此前版本可能接受其他 Python 3.x，但**尚未发布的 v1.0.4 新安装及主动修复候选流程**为确保完整原生依赖 Wheel SHA-256 对照，限定 64 位 Python 3.12（Linux/macOS 可使用 `python3.12` 或确实为 3.12 的 `python3`；Windows 优先 `py -3.12`）；首次需要网络、Python 3.12 的 `venv` 支持和可用磁盘空间；校验 SDK 版本及模型文件哈希通过后才会启用本机推理，缺失时不会静默切回旧引擎。识别后如需断网使用，应先确保模型已完整安装。

**当前公开 v1.0.3 的 Windows / macOS 不提供原生 Moonshine 离线听写。尚未发布的 v1.0.4 源码候选版增加 Windows x64 与 macOS 15+ Apple Silicon 的用户主动安装试点，但不能将其描述为公开版已有功能。** Windows/macOS 公开版仍能使用课程学习与麦克风录音回听。 **v1.0.4 未发布候选版**的 Windows x64 Moonshine 新安装试点要求已安装 64 位 Python 3.12（优先通过 Python Launcher 的 `py -3.12` 选择）；不满足时安装失败并保留既有用户数据。CI 对三个平台的候选推理环境均使用 Python 3.12，其他本机 Python 版本的可用性不得仅凭 CI 推断。当前没有自动发音评分或音素级纠音。更完整的模型目录与安装说明见 [Moonshine Linux 指南](engineering/MOONSHINE-LINUX-INSTALLATION.md)。

## 常见问题

- **示范没有声音**：核对系统音量、输出设备、英语 TTS 引擎及其语音包。
- **无法录音或听写**：核对系统麦克风权限、输入设备连接、设备是否被其他软件占用；Linux 检查模型管理页是否显示 Moonshine 已校验。
- **Moonshine 下载失败**：检查 Python 3/venv、网络、磁盘容量和依赖环境；安装失败不代表模型可用，也不会切换到未验证模型。
- **无法播放上一句的录音**：本版本的录音只在当前练习中临时回听；换句后旧音频会清理。本机历史、收藏和复习记录会保留。
- **Windows SmartScreen / macOS Gatekeeper 警告**：当前公开安装包尚未进行发行者数字签名或 macOS 公证；SHA-256 不等于身份认证。
- **安装失败**：记录安装包文件名、版本、系统版本、操作步骤及脱敏错误提示，到 [GitHub Issues](https://github.com/kunlong-luo/voxnelo/issues) 反馈。不要公开上传私人麦克风录音、系统序列号或私有文件路径。

## 隐私与边界

无需账号、学习记录本地保存。录音在用户同意使用麦克风后才开始，本地 Moonshine 识别不需要向 Voxnelo 服务器上传录音；浏览器体验版如果使用系统 Web Speech 服务则可能受浏览器提供商不同的联网/隐私政策影响。课程文本、TTS 及第三方运行时授权和跨设备实测仍在持续审核。参见 [发行说明](release-notes/v1.0.3.md)。
