# 隐私说明（v1.0.0 免签名正式版 · 待独立复核）

> 本文件针对公开 Early Access 说明本地优先、无账号、无遥测的产品功能，以及主动下载离线模型的联网边界。
> 文档已随公开预览版提供，仍需要独立隐私/法律专业复核，不能视为已获法律认证。

## 我们收集什么

Voxnelo 没有账号或开发者运营的后端，不包含第三方统计或自动崩溃上报。**本地英语麦克风录音和 Moonshine 推理不会默认上传到 Voxnelo 服务器。** Linux 用户主动安装 Moonshine 时，安装器会联网访问 PyPI 与 Moonshine 官方模型分发端点以获取软件包/模型；这些第三方服务可能接收标准下载请求元数据（例如 IP），并适用自己的政策。

## 数据存放在哪里

- 学习记录（浏览/练习计数、收藏、复习标记、历史事件）保存在**你设备本地**
  的 IndexedDB（数据库名 `voxnelo-v01`），卸载应用或清除应用数据时一并删除。
- 录音为**临时内存回放**：通过 Blob URL 在练习界面内回听，切换句子或关闭
  窗口时清除，默认不写入磁盘、不上传。
- 参考朗读调用**操作系统提供的 TTS**：Voxnelo 不将文本上传到开发者服务器，具体系统语音服务是否联网、存储或提供哪些声音由操作系统/语音服务提供者决定。网页体验版若启用浏览器语音识别，可能依赖浏览器厂商的联网服务，与 Linux 本机 Moonshine 的隐私边界不同。
- Linux Moonshine 模型和 Python SDK 在用户主动点击安装后下载到本机；校验成功后识别在本机运行。Windows/macOS 尚不保证同等 Moonshine 本地识别支持。

## 权限使用

- 麦克风：仅在你主动开始跟读录音或实时听写时申请，应用内仅申请音频权限；拒绝后仍可使用听示范、看短句、收藏与历史功能。
- 无通讯录、位置、文件系统等其他敏感权限请求。

## 你的权利

- 查看/删除：学习记录保存在本地，可通过清除应用数据完整删除；
  导出/恢复功能尚未提供（列入 V0.3 路线，见 PRD F107）。
- 儿童与青少年使用建议监护人陪同；课程 IPA 为教学参考，发布前待专家复核。
