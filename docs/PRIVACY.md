# Voxnelo 隐私说明（公开 v1.0.3 / 未发布 v1.0.4 源码候选）

> **更新日期：2026-11-22。** 最新公开正式版是 [v1.0.3（免签名）](https://github.com/kunlong-luo/voxnelo/releases/tag/v1.0.3)；仓库版本 `1.0.4` 仍是**未公开发布的源码候选**。已有的私有 v1.0.4 Draft 构建自旧提交，不包含此后合并的全部功能。下面明确区分不同版本，不把源码功能误写成公开安装包功能。
>
> 本文描述可从产品代码、发行记录核对的行为，**尚待独立隐私与法律复核**；不表示代码签名、Apple 公证、法律认证或全平台真人实测完成。

## 我们收集什么

Voxnelo 是**本地优先**的英语练习应用：不要求注册 Voxnelo 账号，没有开发者运营的学习记录云后端，也不包含应用自身的第三方分析或自动崩溃上报。**桌面本机录音和已安装 Moonshine 的本地推理不会默认向 Voxnelo 服务器上传音频。**

这不代表使用应用时绝不会产生网络访问：用户首次主动安装 Moonshine 时会从 PyPI 和 Moonshine 的模型分发端点下载 Python SDK、依赖与模型，相关第三方服务可能看到通常的下载请求元数据（例如 IP 地址），并适用其自身隐私条款。依赖包、系统语音服务、操作系统更新或用户点击的外部帮助链接也可能使用网络；不要将这些行为描述为 Voxnelo 的语音上传。

## 数据保存在何处

- **学习状态和历史：** 浏览、练习、收藏、复习标记、已熟悉状态及学习事件存于此设备的 IndexedDB（数据库名 `voxnelo-v01`）；不跨设备自动同步，也没有账号恢复通道。
- **练习录音：** 在用户明确授予麦克风权限后采集，默认仅用于本次界面的临时 Blob URL 回听；切换短句或关闭练习窗口时清理，不作为持久录音文件保存或上传 Voxnelo 服务器。
- **参考发音：** 使用设备/浏览器所提供的英语 TTS；Voxnelo 不向自己的服务器发送朗读文本，但系统语音包是否联网、保留何种数据由相应系统或语音服务决定。
- **离线识别：** 公开 v1.0.3 仅对 Linux x64 提供用户主动安装的本机 Moonshine；Windows/macOS 公开安装包**不包含**相同原生引擎。未发布 v1.0.4 源码候选增加 Windows x64 和 macOS 15+ Apple Silicon 的自主安装与本地推理路径；模型及 Python SDK **不随标准安装包内置**。SDK/权重下载及 SHA-256 校验成功后，本机 Moonshine 不需要将音频送往在线语音服务。
- **网页演示：** 浏览器 Web Speech 识别的实现和隐私特征由浏览器供应商决定，可能依赖其在线服务；不能将网页演示的语音识别等同于桌面离线 Moonshine。

## 备份与恢复：按实际版本区分

- **公开 v1.0.3：** 未提供下述 JSON 备份与恢复界面，不应参照候选版指南寻找该按钮。
- **未发布 v1.0.4 源码候选：** 「设置 → 本地学习数据备份与恢复」允许用户**主动导出**学习状态、收藏、历史事件、复习安排及已熟悉标记。文件为保存在用户设备上的**未加密 JSON**，不包含麦克风录音本身、Moonshine 模型、系统设置或系统主音量；务必妥善保管，不要上传公开 Issue。
- **恢复操作：** 由用户选择本地 JSON 文件，在界面预览、明确确认后才会**替换本设备现有的学习数据**；建议恢复前先导出原数据。此功能仍需跨平台实机验收，绝不意味着已公开发布。

文件下载和用户选择文件属于用户主动操作；应用不会因此获得任意读取本机其他目录的权限。

## 权限、删除与保留

- 只有用户主动开始录音或桌面实时听写时才申请麦克风权限；拒绝后仍能学习、收藏、查看历史与使用可用的参考朗读。桌面应用不要求通讯录或位置权限。
- 可以通过系统/应用数据管理手动清除 IndexedDB 学习记录。**仅卸载程序不一定删除操作系统保留的应用用户数据或个人离线模型**；若需要彻底清理，应另行检查系统保留的应用数据目录。
- v1.0.4 用户主动导出的 JSON 文件独立存在于下载位置；**清除应用数据或卸载软件不保证删除这些备份文件**。个人安装的 Python 环境和模型也可能需要独立管理。
- 已发布的 Windows/macOS 安装包未签名、macOS 未公证；SHA-256 是文件一致性校验，不能证明发行者身份。隐私行为、授权条款和实机行为仍需独立核验。
