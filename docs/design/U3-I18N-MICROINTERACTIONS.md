# Voxnelo U3 视觉与中英文国际化实施规范（V0.3）

状态：实现中，供桌面验收。设计参考：仓库 `docs/u3.jpeg`（暖色雾面玻璃与简洁教育应用氛围），结合之前已经确认的三栏结构与真实学习流程。参考图只用于配色、材质、排版情绪，不作为照抄交互位置的规范。用户截图中的控件摆放不合理处按照实用性重排。

## 桌面窗口：到底有没有“系统自带顶部栏”？

Electron 的 `BrowserWindow` 当前已设置 `frame: false`，**Windows / Pop!_OS 桌面原生标题栏已被应用替换**。看到的顶端约 42px 是应用自行绘制的可拖动标题栏，三颗按钮调用已授权 Electron IPC。系统桌面任务栏、窗口边框阴影或平台窗口管理器行为仍由操作系统负责，无法等同于网页标题栏。

设计目标：保留简短、可拖动的自定义窗口区域与真实最小化、最大化/还原、关闭三个按钮；不再叠加系统本地标题、面包屑、头像或营销信息。左侧导航内部的 Voxnelo Logo 和字标**必须保留**。完全移除拖动区域会损害窗口拖拽，不作为默认选项。

## U3 风格重点

- 配色：低饱和桃杏 `#f8f1ed`、燕麦暖白 `#fffaf6`、雾青 `#eef4f0`、深墨绿 `#294744`，按钮点缀温暖珊瑚色。北欧纯净维持已有主题；日落主题继承 U3 的暖纸与微玻璃质感。
- 保留左、中、右三栏及真实学习进度；中央句子及声纹水平和垂直居中，底部同宽对称上一句/下一句。
- **收藏与复习**：都放在练习卡右上同组的两个图标按钮（心形 + 书签）；不附在句子标题上，底栏不再出现“需要复习”文字。二者独立切换、`aria-pressed` 反馈，按钮文本通过应用内 Tooltip 展示。
- 语音五操作依次为示范/慢速/麦克风跟读/停止/回听；麦克风仍为最大视觉强调色。不会按照概念图中的错位布局摆放，录音中保留可见的快捷停录。
- 学习进度从本机记录读取；相关表达和场景都绑定现有课程。装饰性 SVG 波形不声称实时检测麦克风或口语评分。

## 组件与原生外观界限

- **不使用**浏览器 `title` 原生悬停气泡、`window.alert/confirm/prompt`、操作系统原生下拉选择框或原生 `<progress>` 视觉；改用项目的 `Tooltip`、自绘语言选项卡、自绘进度轨和现有应用内状态通知。
- **保留**有语义的 HTML `button`、`input`、隐藏的 `audio`：前两者保障键盘输入和辅助技术，后者负责真实录音回听。这些基础能力并非默认的操作系统皮肤组件，所有可见状态统一由项目 CSS 自行绘制。系统麦克风授权弹窗属于系统安全机制，不应伪造或绕过。
- Tooltip 用 hover + focus-within 激活，在 Electron 顶栏和普通工具按钮一致展示；禁用的按钮仍可显示原因。提供中文/英文动态内容和可访问名称。

## 微动效规范

- 内容切换：主句淡入、上移约 7px、约 310ms，避免剧烈摇晃。
- 可操作按钮：轻微 hover 位移（最多 2px）、点击轻压（约 0.975）、背景/描边约 220ms 平滑反馈。
- 录音中麦克风：2.4s 低幅呼吸光晕，仅对应真实正在录音状态；无录音时静止。装饰波形不模拟实时数据。
- 滚动与窗口控件不做循环或吸引注意的动画；系统开启 `prefers-reduced-motion` 时消除动画、过渡与平滑滚动。
- 真实 UI 的文字对比、键盘焦点、按钮可用状态和性能预算优先于光影美感。

## 国际化（默认自动匹配系统）

- 首次启动设置为 `system`。由 `navigator.languages[0]` / `navigator.language` 推导；`zh-*` 使用简体中文界面，其余语言暂时回退英文。监听系统 `languagechange`。
- 设置 → 界面语言采用项目自绘选项卡：跟随系统 / 简体中文 / English；即时切换整个 React 界面，更新 `<html lang>` 与按钮无障碍名称。
- 用户手动选择后存储在本机 `localStorage('voxnelo.language')`；异常值/存储不可用时退回跟随系统。不会重置录音、学习历史、收藏、复习或主题选择。
- 侧栏、练习操作、学习提示、进度面板、设置、图书馆、窗口操作和异常恢复均提供英汉译文；**课程中的中文译文是学习素材，英文 UI 下仍保留**。
- 新文本在字典 `apps/web/src/i18n.tsx` 中维护；未来新增语言可继续扩展，不允许随意硬编码界面字符串。
