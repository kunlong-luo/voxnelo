# Voxnelo · Nordic Learning 视觉设计系统 v1.0

**状态：实施规范（2026-10-15）**。设计方向：**北欧极简教育 App**，以安静、亲和、阅读舒适、操作明确为目标。保留 `docs/ui2.jpeg` 的信息架构与真实学习操作，不沿用其全屏极光、霓虹、重度玻璃光效。用户明确选择本规范作为本轮 UI 的唯一视觉验收基线。

> 范围：视觉与桌面交互。**不修改** `docs/Voxnelo-Product-Docs-v1.0/` 下任何冻结文档，也不扩展 V0.1 实际产品能力。旧的 [UI2 玻璃拟态规范](DESKTOP-UI2-SPEC.md) 仅作历史参考。

> **后续主题探索**：最新的「暖日落流光玻璃」视觉概念与双主题切换想法已经整理到 [双主题视觉策略与验证计划](DUAL-THEME-VISUAL-STRATEGY.md)。该文是**候选策略**，本规范仍是当前北欧版默认实施基线。日落版与主题切换已在独立原型分支开发，尚未作为对外发布功能交付；原型规范见 [Sunset Glow](SUNSET-GLOW-PROTOTYPE.md)。

## 1. 品牌氛围与原则

1. **专注**：英语短句第一视觉层级，中文翻译第二，课程进度和工具第三，统计侧栏第四。
2. **克制**：暖白画布、鼠尾草浅绿导航、米色学习提示、极淡青绿强调；不使用多重荧光或背光玻璃。
3. **可信**：学习数据取自 IndexedDB；相关表达/相关场景来自真实 40 句课程；不展示伪造的社区动态、实时音波、评分和连续签到。
4. **温暖**：文案简洁，不增加顶部每日口号；系统字体优先，不加载第三方字体或 CDN。
5. **可操作**：按钮有触发状态、键盘焦点、禁用反馈；独立结束录音和顶部录音中快速停止入口必须保留。

| 区域 | 宽屏布局（≥1260px） | 普通桌面（1021–1259px） | 紧凑屏（≤1020px） |

## 2026-10-15 · 主练习台居中与等高卡片修订

这项修订覆盖旧 UI2/Nordic 中上一句和下一句位置不一致、复习文字占据底栏、右侧卡片与主卡不齐的问题。

- **主卡高度**：桌面主练习台使用剩余窗口高度作为最低伸展目标（保留内容自然增高与纵向滚动，不固定高度裁剪）。左侧练习卡与右侧四块学习卡顶部、底部应在同一条基线上。
- **居中焦点**：英语主句、译文、音标、音标开关以及装饰声纹作为中央焦点组，在进度/主题头部与底部操作之间水平、垂直居中；文字换行不改变居中锚点。
- **底部切句对称**：「上一句」与「下一句」都放在主卡同一个底栏，按钮等宽、等高、同风格、两侧镜像对齐，原先动作轨道里的下一句按钮移除。中间可保留轻量提示。
- **复习入口**：从底栏移到课程头部主题标签旁，仅绘制 Bookmark 图标，不显示「需要复习」四字；用 `aria-label`、`aria-pressed`、`title` 保证辅助技术和鼠标可理解状态，保留原有切换逻辑。
- **底部操作**：五项真实操作（示范、慢速、麦克风、停止、回听）以麦克风为水平中心，不能用切句按钮挤偏主操作。
- **右侧四卡**：进度、相关表达、学习提示、相关场景共同撑满与中央主卡一致的高度；本地隐私提醒放入最后一张卡底部，避免右侧末尾留下额外不齐的第五行。
- **响应边界**：800×610 或长句时优先自然纵向滚动，不以 `overflow:hidden` 隐藏按钮；北欧与日落主题共用尺寸规则，Pop!_OS 24 Electron 截图验收待完成。

## 2026-10-15 · 三栏布局与纯操作标题栏定稿（覆盖本文较早顶部栏描述）

**产品最新确认**：桌面学习界面保持左侧导航 + 中央练习台 + 右侧学习信息栏，不允许在普通桌面宽度直接变成上下单列。页面最顶端只展示**真实**窗口最小化、最大化/还原、关闭三个按钮。**左侧导航顶部保留 Voxnelo Logo 与字标**，中上**不放标题/课程名/面包屑**，也不放日期、用户头像或口号。

- **标题栏**：无边框 Electron，约 42px 的可拖动空白区域。Windows / Pop!_OS Linux 三按钮位于右侧，macOS 三按钮位于左侧；三按钮均保持可点击、ARIA 名称、键盘焦点和实际窗口控制 IPC。纯浏览器预览无原生窗口行为时不渲染假的标题栏。
- **左栏**：顶端保留现有 Voxnelo 品牌 Logo / 字标，其下为「我的学习空间」与练习、收藏、历史、复习、设置五项可用导航；窗口压缩到图标导航时仅显示 Logo 图形。
- **中栏**：内容从窗口栏之下立即开始，去掉第二条顶部信息栏。当前句及进度由练习主卡自身承担，历史、收藏和设置也在各自内容卡展示标题。
- **右栏**：仍是本地进度、相关表达、学习提示与场景。普通桌面和紧凑窗口保持左中右；窗口过窄时将侧栏切换为**有 aria-label 的图标模式**，右侧适度收窄，而不优先堆叠到中栏下。
- **录音中止**：旧的“顶部快速停止录音”不再放在应用顶部。中心练习卡仍有独立结束录音按钮，另有一个只在录音时显示的**底部悬浮快捷停止**，滚动后依然可操作且不混入顶端三个系统按钮。
- **主题一致**：北欧纯净和日落柔光共享上述布局；只由主题变量改变配色，不复制 UI 结构。
- **最小窗口**：在 800×610 测试三栏布局是否无横向溢出；紧凑按钮、键盘聚焦、纵向滚动与录音中止可达必须通过实机验收。

以上为最新覆盖性规范；Logo 位于左侧导航区，Electron 可拖动标题栏只保留三个真实系统操作按钮。下面旧「顶部面包屑/品牌标题栏」表述为历史记录，不再作为实现依据。

## 4. 自定义 Electron 窗口顶部栏（替换原生 Titlebar）

- 顶部增加全窗宽 **46–50px** Nordically styled 标题栏：浅鼠尾草背景、细分隔线、Voxnelo 标识、低对比度「英语口语练习」副标题；页面内部原面包屑行保留在其下，避免牺牲课程上下文。
- Electron `BrowserWindow` 使用 `frame: false`、`titleBarStyle` 不再依赖 OS 原生控件：提供自绘 **最小化、最大化/还原、关闭** 按钮。macOS 按钮排列在左，Windows/Linux 在右；实际图标非装饰，单独设置 aria-label 和 hover/focus 态。
- 标题栏空白区域采用 Chromium/Electron 的 `-webkit-app-region: drag`，交互按钮和菜单必须 `no-drag`，允许拖拽和双击最大化/还原。失焦仍使用稳定背景，不隐藏退出控制。
- Electron preload **只暴露明确的窗口动作**（minimize/toggleMaximize/close/getMaximized）与最大化事件监听；不暴露通用 `ipcRenderer`。主进程验证发送方所属 BrowserWindow 与可信 URL，拒绝非受信任的 frame。
- 纯浏览器预览没有桌面动作接口时，不渲染假的窗口按钮；页面依然显示品牌顶部栏。macOS/Windows/Linux 仍需实机验证窗口缩放、系统菜单快捷键、拖动/双击效果。
- 顶部录音中「快速停止录音」继续显示在页面二级顶部栏，滚动后可见，且不被自定义标题栏覆盖。

## 5. 模块层级与状态

- **导航**：练习、收藏、历史、复习、设置 5 个真入口；选中态为鼠尾草底色和深青文字，没有霓虹边框；底部仅提示本地隐私。
- **练习中心**：课程位置与分段进度，主题标签；中央英文/翻译/可切换音标；收藏 icon；淡绿色声纹细线只是 **SVG 装饰**，使用 `aria-hidden`；底部横向六操作（示范/慢速/跟读/结束/回听/下一句），麦克风为唯一强调色大按钮。
- **录音**：请求权限时禁止重复操作；录音中主要按钮保留 disabled 状态，独立「结束录音」与顶部快速停止可操作；屏幕缩小时顶部按钮仍可见。语音示范与录音不重叠。
- **右栏**：本地学习进度（真实浏览数量 / 课程总数 / 尝试句数 / 收藏 / 复习），相关表达（同主题真实短句）、提示、相关场景（点击进入实际课程）。不要把“相关表达”命名成社交 feed。
- **收藏/历史/复习**：相同暖白卡片样式与搜索框，无数据时空状态友好，不变更学习服务的数据协议。
- **设置**：真实会话级语速和音标开关；不要暗示已持久化存储；仅说明既有隐私行为。

## 6. CSS 架构与资源

- 基础布局沿用 `apps/web/src/styles.css`（原有业务与兼容性）。
- **唯一激活主题**：`apps/web/src/nordic.css`；`main.tsx` 不再加载旧 `ui2.css`。移除不再使用的 UI2 玻璃主题 CSS，避免并行视觉系统与不可维护的选择器叠加。
- 品牌仍使用 `public/brand/voxnelo-mark.svg`；应用不引用效果图作为背景，不新增网络资源。移除荧光装饰光圈，淡绿色低对比 SVG 波形仅作视觉分隔。
- 降级原则：无 `backdrop-filter` 时仍可使用；实际主主题不依赖模糊效果。
