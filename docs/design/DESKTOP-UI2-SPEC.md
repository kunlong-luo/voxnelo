## 2. 视觉 token

- **背景**：分层 aqua / cyan / sky / warm gold radial gradients；无联网图片、无外部字体。
- **玻璃**：面板底为带色半透明渐变，描边 `rgba(246,255,255,.44)`，模糊 `blur(20–25px)`，高光内描边和低对比阴影。
- **品牌**：保留既有 Voxnelo SVG Mark + 字标；侧栏渐变透明，底部为本地学习说明，不恢复顶部每日英语宣传口号。
- **文字**：冰白高对比主句，柔白辅助标签；重要点击区域可见键盘 focus-ring。
- **动作**：录音为 79–110px 蓝绿渐变大圆，外围双环光晕；停止独立显示为可聚焦按钮，录音中高亮。

## 3. 响应布局

1. **宽屏（大于 1250px）**：左栏 176–226px；中间练习主卡 + 右侧 245–330px 学习栏；卡片目标高度约 565–738px。
2. **普通桌面（1001–1250px）**：左栏约 181px；右栏约 245px；主卡填充剩余宽度。
3. **紧凑窗口（不大于 1000px）**：中央练习台优先，统计/提示等右栏移至练习卡下方双列；不可隐藏麦克风或停止按钮。
4. **窄桌面（不大于 860px）**：左栏约 142px，顶栏/按钮收紧；最低建议 800×610。高度不足时允许纵向滚动；顶部提供录音中常驻快速停止按钮。
5. **无障碍**：装饰 SVG 对辅助技术隐藏；按钮状态、disabled、ARIA 标签完整；尊重系统减少动画设置；滚动条与玻璃主题协调。
