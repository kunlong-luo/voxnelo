# Voxnelo 桌面视觉系统（V0.1）

> 工作品牌，商标仍需核验。蓝绿品牌方案以之前的视觉概念稿为方向，已实现为可版本管理的 SVG；最终视觉请以运行中的 Electron 截图和实机检查为准。

## 资产

- \`public/brand/voxnelo-mark.svg\`：透明/深蓝底 V+声波符号，应用左栏和站点使用。
- \`public/brand/voxnelo-wordmark.svg\`：包含 Voxnelo 字样的横版 Logo，用于 README 和宣传材料。
- \`build/icon.png\`：512×512 桌面打包图标，根据相同 V+声波语言程序化绘制。不是直接复用展示图的像素。

## 设计原则

- **视觉**：深海军蓝导航（#071b39 / #0b2852）；霜蓝内容底（#eff6ff）；白卡片；动作用蓝色（#2775f2）到青绿（#0dbbc2）渐变。
- **体验**：一句英语为唯一主视觉重点；中文紧随其后；录音为主要操作；慢速、复习、收藏可随时使用。
- **可信**：只展示真实浏览/录音尝试/收藏/复习的本地数据；不创建假音波、假准确率、假会员标识。
- **录音**：明确的麦克风使用状态；只有真实录音可播放。页面切换和录音互斥逻辑沿用安全 PR。
- **无障碍**：保留 aria-label、可见键盘焦点、减少动态效果、禁用状态、桌面缩放响应。
- **字体**：仅系统字体，无在线字体请求；无需账号/广告或云端依赖。

## 发布前

1. 实机检查 800×610 最小窗口和正常桌面尺寸，不允许按钮遮挡、溢出。
2. Linux/Windows/macOS 对比图标、浅色卡片、滚动/键盘操作。
3. 音频结束/回放/拒绝权限/切句均检查其提示；必要时优化色彩对比度。
4. 产品商标核验完成后再定稿应用图标，Windows \`.ico\` 与 macOS \`.icns\` 需对应打包系统生成和验收。


## 第二轮桌面细节调整（滚动条与交互）

- 内容区采用 9px 的浅轨道和圆角蓝灰滑块；侧栏采用 7px 的深蓝轨道与浅蓝滑块。优先使用平台支持的细滚动条样式，Windows/Linux Chromium 和 Firefox 使用各自支持的 CSS 属性实现；系统若强制覆盖外观，以可访问的系统设置为准。
- 侧栏仅在高度不足时单独滚动，导航尽量保持在视野内；顶部页面导航缩至 62px，突出英语练习主体。
- 按钮和历史条目统一焦点、hover、pressed、disabled 状态；系统减少动画时关闭动效。
- 保留 Electron/操作系统的原生窗口标题栏和窗口控制按钮，不为了装饰而牺牲窗口拖拽、最大化及平台兼容性。
- 验收：低高度窗口滚动侧栏；长历史列表滚动；深色侧栏和浅色内容的滚动条不会混色；键盘导航可见；滚动不会影响麦克风状态。
