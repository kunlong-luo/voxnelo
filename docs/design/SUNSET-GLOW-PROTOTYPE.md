# Sunset Glow · 日落柔光主题原型实施与验收

> **2026-10-15 U3 更新**：最新实施基线见 [U3 视觉、国际化和微动效规范](U3-I18N-MICROINTERACTIONS.md)。新安装默认日落柔光；手动选择的北欧偏好继续生效。本页较早的默认主题描述仅为历史记录。

> 实验性视觉原型 · 2026-10-15。基于用户提供的柔和日落玻璃参考图，不把参考图本身用作应用壁纸，也不增加未实现的社交、发音评分或 VAD。

## 产品决策与实现现状

- **默认主题仍为 Nordic Clean**。新主题是可选对比原型，不替代已通过 CI 的 PR #13 北欧实现，也不代表已获得真实用户偏好证据。
- 设置 → 外观主题现在可以实际切换 **北欧纯净 / 日落柔光**；通过 `localStorage` 记住用户在本机明确选择的外观，数据不可用或内容异常时退回北欧主题；无网络调用。
- 两套外观复用 **同一份** `App`、`PracticeView`、`RecordingPlayback`、`DesktopTitlebar`、`LibraryView`、`SettingsView` 与学习数据服务。无主题专属业务分支。
- 方案与评估背景见 [双主题策略](DUAL-THEME-VISUAL-STRATEGY.md)。此文属于 UI 原型与验收说明，不修改 `docs/Voxnelo-Product-Docs-v1.0/` 的产品承诺。

## 实现架构

- `apps/web/src/nordic.css`：共享布局与默认北欧主题基线。
- `apps/web/src/sunset.css`：仅包含 `[data-theme='sunset']` 视觉修饰、少量与两个主题通用的外观选择卡片样式；避免第二套 React 页面。
- `apps/web/src/appearance.ts`：主题枚举、输入校验、安全回退、本地持久化/DOM 应用，不接触 Dexie 或麦克风。
- `apps/web/src/main.tsx`：首屏挂载前应用已保存的主题，减少颜色闪烁。
- `apps/web/src/App.tsx` 与 `SettingsView.tsx`：提供真实可访问的两张主题选择卡片及选中反馈。
- Electron 原生窗口背景仍采用初始中性色；主题只影响渲染层，不修改应用的录音权限或窗口 IPC。

## 视觉规格与限制

| Token 候选 | 值 | 用途 |
| --- | --- | --- |
| 桃粉基调 | `#EBC6B7` | 背景边缘柔光，不放在正文下方 |
| 雾青基调 | `#E7F1EE` | 低饱和底层，兼顾北欧清爽感 |
| 纸感面板 | `rgba(255,251,247,.88)` | 侧卡，防止过度透明影响可读 |
| 主文字 | `#2B3E40` | 稳定的深色阅读区 |
| 珊瑚主强调 | `#C97970` | 录音主按钮和少量选中信息 |
| 青绿辅助 | `#477E78` | 次要交互与焦点颜色 |

**不复刻** 截图中的示意进度数字、机器人、真人场景缩略图、假头像身份或不支持的社交动态。也不恢复此前被移除的顶部每日英语标语。
