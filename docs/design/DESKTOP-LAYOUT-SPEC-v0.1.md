> **历史布局规范**：自 2026-10-15 起当前设计基线为 [Nordic Learning v1.0](NORDIC-LEARNING-DESIGN-SYSTEM.md)，包括自定义无边框顶部栏；以下内容为原 UI2 前的设计记录。


状态：**布局实施规范**（不是产品 PRD 修订）。依据 2026-10-15 讨论中的原始概念图《Voxnelo language practice dashboard》（约 1534×960 横向视觉稿），以当前 V0.1 真实功能为准，优先落实布局与操作层级。

## 1. 为什么重新布局

上一轮已统一色彩、Logo 和滚动条，但组件仍沿用上下堆叠的「表单式卡片」，未落实原图的空间秩序：

| 区域 | 原图可观察特征 | 现有代码问题 | 本轮规范 |
| --- | --- | --- | --- |
| 左栏 | 深蓝整高、Logo 在上、4–5 个大导航 | 视觉基本正确，但底部重复口号 | 保留深蓝导航、去除重复营销内容；不要凭空加入不可点击设置 |
| 顶栏 | 内容区域内短面包屑，右侧弱提示 | 现有 62px，基本接近 | 保持 62–68px，非原生窗口标题栏 |
| 中心卡片 | 纵向高卡，顶部进度，中部英语/翻译，底部环形操作 | 卡片偏矮、主句字号弱，控制按钮垂直堆叠 | 高卡布局 + 一条横向控制轨道；句子视觉居中 |
| 右栏 | 统计、提示、相关内容三块纵排 | 独立卡片太散；高度不受约束 | 统计置顶、提示在下；展示真实本地数据，不硬造第三块场景入口 |

| 记录进度 | 圆环+统计 | 原图数字多为虚构样例 | 只允许真实 IndexedDB 的 viewed/practiced/favorites/review，不展示连续学习天数、今日时长 |

## 2. 视觉结构与尺寸约束

黄金参考截图为宽屏示意，**不等于**实际 1160×760 默认窗口的像素坐标。工作台采用自适应布局，在默认窗口保持主要操作可见；绝不拉伸到必须横向滚动。

* **宽屏 1440px 及以上**：侧栏约 240–255px；内容左右留白 24–30px；主卡片占剩余内容宽度的约 69–72%，右栏约 300–340px；两栏间距 16px。主卡片目标高度 680–740px，主句居中。
* **标准桌面 1080–1439px**：侧栏约 205–230px；右栏约 240–270px；主卡片最小可用宽度约 540px；功能栏可以根据空间压缩间距，但不能隐藏结束录音。
* **紧凑窗口 800–1079px**：左栏收至约 176–190px，内容区**主卡片在前、统计区在后**纵向排列；控制轨道允许两行换行，主录音按钮仍显著；严禁水平溢出。
* **窗口高度 610–759px**：主卡片自然变矮并允许纵向页面滚动。不要依靠固定高度把停止按钮裁掉。
* **侧栏滚动与系统标题栏**：沿用现有薄滚动条；保留 Electron 原生窗口标题栏及系统控制按钮。

## 3. 交互和状态（不可因视觉改版退化）

1. **开始录音**：音频示范先停止；请求权限时禁用重复点击；正式录音后展示可见状态。
2. **结束录音**：保留显式、键盘可操作的「结束录音」按钮；正在录音时即使缩小窗口也不能被其他内容遮住且导航仍被拦截。
3. **回听**：没有录音时禁用；获得本次录音后可播放/暂停，播放进度来自真实 HTML audio，不做模拟声纹。换句后临时 Blob URL 被清理。
4. **示范 / 慢速**：录音期间禁用，慢速只切换系统 TTS 速率，不承诺专业音频。仅一处明显的功能入口。
5. **收藏、复习、上/下句**：使用已存在的学习服务；不增加暗中的计数或解锁机制。
6. **音标**：默认收起，点击可展开。原图的 IPA 可见只是示例；为避免屏幕拥挤和未经复核的教学误导，交互保持用户自主。
7. **无障碍**：至少 40px 点击区域，主要按钮 72px 以上；键盘焦点明确，标签中文；decorative graphic 使用 aria-hidden；遵守 prefers-reduced-motion。
8. **可信统计**：总课程数量来自 SENTENCES.length；进度条使用真实已浏览句数；没有今天学了 12 分钟、连续 7 天、三颗星发音准确率等伪数据。

## 4. 视觉 Token 和版式

* 主色：深海军蓝 #071b39 / #0b2852，主操作 #2775f2，强调青绿 #0dbbc2。
* 页面背景：#eff6ff；卡片以白色为主体；圆角约 22–26px；阴影轻、柔。
* 练习中心句：桌面按可用宽度缩放，目标 45–68px；译文 20–24px；句长自动换行，不允许越界。
* 卡片顶部：进度编号（当前第几句/总句数）+ 真实进度轨道 + 主题；不是闯关关卡。
* 控制轨道：大录音键作为视觉轴，左右环形图标按功能组等距排列，标签不与其他按钮重叠。
* 边距：外框 18–28px，卡片内部 24–32px；底部复习与收藏保持次级操作。
* 保留之前用户要求：**顶部不再放“每天开口说一句英语”等宣传标语**；页面打开立即出现教学内容。

## 5. 验收规则

- [ ] 宽屏约 1440×900 时显示完整的左侧导航 / 中心练习大卡 / 右侧真实统计三栏。
- [ ] 默认 Electron 1160×760 可以直接看到开口练习与结束录音的对应位置。
- [ ] 最小 800×610 无水平溢出，主要按钮不被裁切，统计可以下移并通过滚动访问。
- [ ] 无录音时回听禁用；正在录音时停止可见，示范禁用，导航切换受限制。
- [ ] 收藏、复习、换句、音标、实际学习统计与上一版功能相同。
- [ ] 自动化测试检验布局关键区块、禁用状态和语义，无虚构成绩。
- [ ] CI 的类型检查、Lint、架构测试、覆盖率和构建通过。
- [ ] 最后仍须 Linux/Windows/macOS Electron 实机截图验收（CI 成功不能代替外观检查）。
