# Voxnelo · 动效库与历史学习中心 UI 决策（2026-10-16）

## 用户决策

优先保证美观度和功能体验，**正式允许引入成熟第三方动效库**，不再把 169 KiB JS / 24 KiB CSS 等极低静态体积阈值作为合并门禁。体积需要继续被统计报告，但不阻断设计实现；类型、Lint、实际行为、无障碍、响应式、Electron 安全和真实 UI 截图仍必须验收。

## 依赖选择

- 引入 `@formkit/auto-animate@0.10.0` 正式生产依赖（MIT），用在学习记录列表的增加、筛选、翻页和布局变化。使用其 React Hook `useAutoAnimate`，不是业务代码手写 CSS 动画。
- 无需增加整套 UI 框架；继续 Tailwind 4、Base UI 和当前语义 token。动效应尊重用户偏好与低动态效果要求，避免录音动画伪装声音识别。
- `pnpm perf:budget` 在 CI 里只报告压缩体积，不再因固定字节阈值失败。遇到实际资源性能问题仍需通过耗时、内存、布局或访问行为诊断，而不是人为禁止功能。

## 历史 UI 的实际模型

旧历史页把 `events` 去重成句子集合，既没有时间线，也没有分页，重复学习活动被错误压平。新的页面应使用 `HistoryEvent {id,sentenceId,at,type}` 真实数据：

- 真实学习事件倒序，日期分组；每条包含英语、中文、主题、浏览/录音动作与本地时间。
- 摘要卡只展示**目前已加载**的真实活动数、不同句子数和录音尝试数，绝不把它们称为总学习天数或发音评分。
- 8 条/页，支持上一页、下一页、数量区间。筛选或搜索时回到第一页。数据量小时不渲染伪分页按钮。
- 可按“所有／浏览／录音”筛选，支持中英文搜索；主题占比也来自真实事件计数。
- 收藏、复习页仍按保存状态展示句子，而非误把它们转换成事件日志；共用高质感卡片和同一分页模型。
- 当前数据服务最多从 IndexedDB 读取最近 **250** 个事件，因此摘要和分页覆盖的是本地已加载的近期记录，而不是永久档案全部事件。

## 验收

`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm perf:budget`（报告型）、Chromium 六档截图几何、Linux Electron 窗口、Windows/macOS 打包。冻结的 `Voxnelo-Product-Docs-v1.0` 不修改。本次不新增跟用户账户、语音识别评级或使用天数有关的虚构统计。

## 全局工作台第二批视觉修正

- 不是只让历史页变精致：左侧桌面导航同步使用层级渐变、轻高光、明确的激活侧边标识及柔和材质卡，保留顶端品牌与导航、底部本地隐私信息，未增加用户已要求移除的每日口号。
- 使用正式接入的 `@formkit/auto-animate` 为右侧“相关表达”真实条目在切句时的布局变化添加轻量动画；与历史事件列表共用动效引擎，减少生硬布局跳变。不绘制假声波、不伪造学习指标。
- 响应式折叠导航、系统窗口自定义标题栏、主卡唯一较重玻璃磨砂层及双色主题保持一致。
