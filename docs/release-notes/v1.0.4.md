# Voxnelo v1.0.4 — 跨平台离线听写维护版（发布前候选）

> **当前仅是待审查的版本说明，尚未公开发布 v1.0.4。** 最新正式下载仍是 [v1.0.3](https://github.com/kunlong-luo/voxnelo/releases/tag/v1.0.3)。本候选计划延续维护者选择的**免签名**发行；Windows 未获受信任发布者签名、macOS 未经 Apple 公证，SmartScreen / Gatekeeper 可能警告或阻止安装。SHA-256 仅验证字节完整性，不能证明开发者身份或所有设备安全。

## 从 v1.0.3 的变化

- **三平台用户主动安装的本机英语听写**：Linux x64、Windows x64 和 macOS 15+ Apple Silicon 对 Moonshine Voice `0.0.65` 采用同一 PCM / 原生 Worker 协议。模型管理页面会先要求用户主动开始安装 Python 虚拟环境、固定 SDK 和经过 SHA-256 验证的私有 English Medium Streaming 模型；安装或校验失败保持禁用，不上传音频，也不伪造字幕。
- **安装程序与原生推理 CI**：PR #174/#175 的三平台原生 SDK、模型与音频协议验证，PR #176 的实际打包后 Electron + ASAR Worker 检查，都通过了真实本机 SDK 推理而非 mock。合成静音 PCM 仅用于传输和终止事件验证，**不能算真人准确率测试**。
- **本地离线评估记录**：PR #177 支持同一批私有已知文本英语 WAV 按安静、外部设备播放、噪声分别统计加权 WER、RTF、首次中间回调及模型加载时间。PR #178 加强报告路径和错误文本隐私。离线快速输送 WAV 的回调时间不等于麦克风到屏幕的延迟。
- **发布草稿门禁**：PR #179 将三系统打包后的真实 Moonshine 原生矩阵接入私有 Draft 的前置门禁。普通打包通过不再足以组装一个 Draft。
- **分段听读（F102，部分实现）**：在发音指南中手动选择短语，用系统 TTS 播放所选片段，再使用原有录音回听。当前不裁剪录音、没有词级对齐或自动评分；短语分组及连读 IPA 仍待教学审查。
- **间隔复习（F104）**：按明确的人工复习标记及真正完成的练习日期，采用 1 / 3 / 7 / 14 / 30 天复习间隔；单纯浏览不会推进复习，不把手动完成伪造成录音成绩。跨时区和长期实机回归仍待验证。
- **已熟悉与筛选（F106）**：人工标记「已熟悉」，在收藏/已熟悉列表中切换与搜索；该标记不代表 AI 推断的熟练度，兼容旧学习数据。
- **JSON 学习数据备份（F107）**：用户主动导出/确认恢复收藏、练习历史、状态及复习计划。JSON 文件未加密，恢复会替换本机学习数据；不包含录音、模型、系统设置，跨设备实机恢复仍待验收。
- **独立播放音量（F107）**：可选 0% / 25% / 50% / 75% / 100% 级别，控制示范 TTS、已有 WAV 播放和录音回听；不影响系统音量、麦克风输入增益或 ASR。真实设备音频表现仍需确认。

## 当前安全与工程验证进展（2026-11-23）

- **完整本地依赖完整性保护**：Linux x64、Windows x64、macOS 15+ Apple Silicon 的可选 Moonshine 新安装/修复均限制使用 64 位 Python 3.12；应用将三个平台的固定 13/14/13 个 Python Wheel SHA-256 与 PyPI 文件摘要及仓库存档清单对照，私有暂存下载完成后逐个重算哈希，然后只从本地核验 Wheel 目录安装。额外文件、篡改文件、依赖版本或 Python ABI 不一致都拒绝启用。已经安装的用户个人模型不会自动迁移或删除。
- **CI 与待人工审核严格分离**：三平台 Moonshine SDK / 真实模型 / 打包后 Electron Worker 已通过自动化验证；原始 Wheel ZIP 许可证和原生库文件清单已留存用于逐项审查。自动化通过不能替代官方八文件不可变来源和许可证授权确认，也不能替代真实真人麦克风的安静/噪声加权 WER、首次可见字幕和停止后最终字幕的延迟测量。
- **基于最新主分支的安装包**：现有私有 Draft 仍来自旧提交 `4aeb58e`。最新主分支的三平台**只读候选包工作流**与当前 Node 26 / pnpm 12.22.0 对齐，但只有成功产出并完成文件哈希验证后，才能按实际 CI 运行号和提交 SHA 引用新候选包；未经实机验收不自动替换旧 Draft 或发布。
