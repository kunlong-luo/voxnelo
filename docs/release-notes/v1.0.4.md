# Voxnelo v1.0.4 — 跨平台离线听写维护版（发布前候选）

> **当前仅是待审查的版本说明，尚未公开发布 v1.0.4。** 最新正式下载仍是 [v1.0.3](https://github.com/kunlong-luo/voxnelo/releases/tag/v1.0.3)。本候选计划延续维护者选择的**免签名**发行；Windows 未获受信任发布者签名、macOS 未经 Apple 公证，SmartScreen / Gatekeeper 可能警告或阻止安装。SHA-256 仅验证字节完整性，不能证明开发者身份或所有设备安全。

## 从 v1.0.3 的变化

- **三平台用户主动安装的本机英语听写**：Linux x64、Windows x64 和 macOS 15+ Apple Silicon 对 Moonshine Voice `0.0.65` 采用同一 PCM / 原生 Worker 协议。模型管理页面会先要求用户主动开始安装 Python 虚拟环境、固定 SDK 和经过 SHA-256 验证的私有 English Medium Streaming 模型；安装或校验失败保持禁用，不上传音频，也不伪造字幕。
- **安装程序与原生推理 CI**：PR #174/#175 的三平台原生 SDK、模型与音频协议验证，PR #176 的实际打包后 Electron + ASAR Worker 检查，都通过了真实本机 SDK 推理而非 mock。合成静音 PCM 仅用于传输和终止事件验证，**不能算真人准确率测试**。
- **本地离线评估记录**：PR #177 支持同一批私有已知文本英语 WAV 按安静、外部设备播放、噪声分别统计加权 WER、RTF、首次中间回调及模型加载时间。PR #178 加强报告路径和错误文本隐私。离线快速输送 WAV 的回调时间不等于麦克风到屏幕的延迟。
- **发布草稿门禁**：PR #179 将三系统打包后的真实 Moonshine 原生矩阵接入私有 Draft 的前置门禁。普通打包通过不再足以组装一个 Draft。

## 计划提供的安装包（候选，非下载链接）

| 平台 | 候选文件 | 限制 |
| --- | --- | --- |
| Linux x64 | `Voxnelo.deb`、`voxnelo_1.0.4_amd64.deb`、`Voxnelo-1.0.4.AppImage` | Debian/Ubuntu/Pop!_OS；首次 SDK/模型安装需 Python 3 与网络 |
| Windows x64 | `Voxnelo.Setup.1.0.4.exe` | 本机 Python 3.10+ 及可用的 Python Launcher / PATH；未签名 |
| macOS 15+ ARM64 | `Voxnelo-1.0.4-arm64.dmg` | Apple Silicon；未签名、未公证，不支持 Intel Mac 的 Moonshine 原生轮子 |

模型不随安装包内置；Python 原生 SDK 同样**不随安装包内置**。Windows ARM64、macOS Intel / 14 或更早版本不可宣传支持本轮原生 Moonshine。升级不应要求卸载旧版，也不会主动清除历史、收藏、个人模型或临时录音；发布候选需要进一步验证升级保持。

## 验收状态及尚未完成的证据

- 维护者先前已确认其既有人工测试通过，**不再重复要求同一轮手动测试**。

- #123 尚未收齐至少 20 条已知参考句的私人实际语音评估、分场景加权 WER、CPU/RAM 与实际端到端延迟。评测音频和完整个人路径不得上传仓库。
