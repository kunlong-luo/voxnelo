# Voxnelo v1.0.3 — 正式免签名维护版

> **正式版本（非 Beta）**。本次 Linux/Windows/macOS 安装件仍未数字签名，macOS 未经 Apple 公证。系统 SmartScreen、Gatekeeper 等可能拦截安装。SHA-256 只验证下载文件完整性，**不代表开发者身份认证、外部安全审核或全部设备兼容保证**。

## 从 v1.0.2 更新

- **停止后快速继续（PR #170）**：等待上一轮音频工作线程最后 PCM 和原生最终识别真正释放后，再启动第二轮本地听写；不再因“刚点停止马上开始”而误报忙碌，等待时仍可取消。
- **流式字幕更可靠（PR #171）**：统一保护 Moonshine 中间字幕、已完成片段与结束事件的共享状态；阻止迟到回调污染结束后的字幕，长时间连续使用不会无限积累已完成文本。
- 新增快速重启、等待取消、长时间历史上限及 8 线程并发字幕测试。
- 个人离线识别模型、学习历史与收藏保持原位置；正常升级**无需卸载旧版或者重新安装模型**。不主动上传麦克风语音。

## 维护者人工测试确认

2026-10-25，维护者明确反馈 **“需要人工测试的已经测试通过了。”** 本版按该维护者反馈记录现阶段人工测试通过，不再反复要求重复操作。

这不是公开可复算的 WER/RTF 评估、逐设备测试证据或外部独立认证。**尚未完成**具有可公开核验材料的定量 WER/RTF 归档及独立教学/模型权利审查；不能以维护者确认代替五位英语初学者独立审核，也不能推断 Windows/macOS 已具备原生 Moonshine 推理。详见 [人工测试状态记录](../engineering/MANUAL-QA-OWNER-2026-10-25.md)。

## 下载与平台限制

| 平台 | 真正的官方安装件 | 注意 |
| --- | --- | --- |
| Linux x64 (Debian/Ubuntu/Pop!_OS) | `Voxnelo.deb` / `voxnelo_1.0.3_amd64.deb` | 两 DEB 内容相同，支持原位升级 |
| Linux x64 (AppImage) | `Voxnelo-1.0.3.AppImage` | 系统库依赖与兼容性需满足 |
| Windows x64 | `Voxnelo.Setup.1.0.3.exe` | 未签名；不承诺 Linux Moonshine 的原生推理支持 |
| macOS Apple Silicon (ARM64) | `Voxnelo-1.0.3-arm64.dmg` | 未签名、未公证；不承诺 Intel Mac |

三个平台分别提供 `SHA256SUMS-linux.txt`、`SHA256SUMS-win32.txt`、`SHA256SUMS-darwin.txt`。仅从 [Voxnelo GitHub Releases](https://github.com/kunlong-luo/voxnelo/releases) 获取文件。

### 已知限制及未完成事项

- Linux x64 实时英语听写默认使用 Moonshine Medium Streaming，**模型不随安装包内置**；必须在模型管理页面由用户主动安装并校验本地 SDK/模型，首次安装需要网络，后续推理在本机离线。
- Windows/macOS 提供实际实现的学习练习、系统 TTS、麦克风录音回听、历史、收藏等功能；**暂不承诺同等 Moonshine 原生离线听写**。没有虚构语音识别、自动发音评分或逐词纠正。
- 自动化 CI 包含高危依赖安全审计、跨平台实际构建、Linux DEB apt 安装、真实模型合成参考语音集成测试及 SHA-256 校验。这些检查和维护者的人工确认均**不自动提供**20+ 真实参考句的定量口音/外放/噪音 WER、各系统原生音频 ABI/许可及独立教学审查结果。
- #45、#123 的跨平台原生 ASR 和精确测量相关工作仍依各自 Issue 单独进行；F001–F012 和教学内容/版权门禁未存档的项目不擅自标记为第三方认证通过。
- 以前发布的 v1.0.0、v1.0.1 和 v1.0.2 标签与所有安装包**原样保留、绝不覆盖**。免签名发行属于维护者已有的授权决定，不代表签名或公证已完成。
