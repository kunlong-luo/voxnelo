# Voxnelo v0.1.7 — Early Access 补丁候选

> **尚未公开发布。所有拟发布安装包仍未签名，macOS 未公证；不是稳定版。**

## 本次修复
- **依赖安全（#139 / #138）**：同步升级 Vitest 和 coverage-v8 至 4.1.12，移除旧 tinypool 与 glob@10.4.5。完整 `pnpm audit --audit-level high` 再次成为严格 CI 门禁，包括开发依赖。Moonshine Python 依赖另行审计；漏洞扫描不代表所有供应链、wheel 来源或许可已得到验证。
- **Linux Moonshine 模型修复（#136）**：仅在用户主动操作后下载或修复，使用隔离目录、固定哈希及 SDK 版本验证，校验后才替换受管资源，失败时回滚并保护个人文件。
- **安装阶段反馈（#137）**：模型管理界面呈现实际 Python、SDK、模型下载、校验与激活阶段，不虚报百分比或暴露第三方安装日志、本机路径。
- **录音权限取消（#142 / #38）**：等待操作系统麦克风授权时，可从录音按钮主动取消应用端请求；旧授权晚到不会自动开始录音或抢占新请求，切句会清除旧权限错误。取消不会强行关闭系统授权弹窗。

## Linux Early Access 与跨平台安装包边界
候选目标为 Linux x64 DEB / AppImage、Windows NSIS EXE、macOS DMG 和各平台 SHA-256 清单。当前**没有 v0.1.7 公开下载**；用户应使用 [现有 v0.1.6 Early Access](https://github.com/kunlong-luo/voxnelo/releases/tag/v0.1.6)。

Linux x64 默认英语实时离线听写引擎仍为 Moonshine Voice Medium Streaming，需要用户在离线模型管理页同意下载 Python SDK 与模型，首次安装要联网；模型不随安装包内置，不会静默回退到 Zipformer。Windows/macOS 安装包提供基础英语练习、录音回听等功能，不承诺具有 Linux 同等原生 Moonshine 推理能力。本地学习记录和个人模型应保留，升级回归仍需实机复核。
