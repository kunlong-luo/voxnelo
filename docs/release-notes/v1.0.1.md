# Voxnelo v1.0.1 — 正式维护更新（免签名）

> **正式补丁版本，不是 Beta。Windows/Linux/macOS 安装包均未签名；macOS 未通过 Apple 公证。** Windows SmartScreen / Smart App Control 和 macOS Gatekeeper 可能警告或阻止安装。SHA-256 验证完整性，不验证发布者身份。

## 本次修复
- **录音停止异常恢复（#159）**：麦克风设备丢失、系统同步抛出 `MediaRecorder.stop()` 异常时，不应产生虚假的完成练习、上一句录音或遗留的资源。
- **录音组件卸载清理（#160）**：在切句或退出时即使原生停止抛出异常，也关闭麦克风 tracks、解绑过期回调、撤销临时 Blob URL，防止晚到事件恢复已失效音频。
- 更新应用及五个 workspace 包的版本号至 1.0.1，更新 Linux AppStream 发布记录；不修改既有 IndexedDB 数据模式、课程记录路径和个人 Moonshine 模型目录。
- 继续使用已合并的 Vitest v4 与严格的高危依赖审计，保留受控 Moonshine 安装阶段提示和日志隐私过滤。

## 能力与尚未完成的验收
- Linux x64 可在用户**主动同意**后独立下载安装 Moonshine Medium Streaming Python SDK 和模型，首次需要联网，之后在本机离线识别。**模型不随安装包内置**；Windows/macOS 仅承诺基础练习与录音回听，不承诺同等的原生 Moonshine 流式听写。
- 系统 TTS 是设备语音，而非经过人工审校的真人示范。不提供自动发音评分或逐词纠错。
- PR CI 和发布流水线必须分别完成测试、依赖安全审计、三平台打包检查、安装包 SHA-256 与 Linux apt 实际安装。**这些自动化不能替代**跨设备拔插/噪声/录音权限真机实测。
- F001–F012 真人验收、内容/IPA 权利和教学审校、五位目标初学者测试、Moonshine WER/RTF 与不同平台支持仍未全部获得独立证据。不要把本次正式发行误解成外部安全、硬件、教学或版权认证。
