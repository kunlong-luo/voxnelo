| 平台 | 安装包 | 注意事项 |

| macOS · DMG 桌面安装 | `*.dmg` | **未签名/未公证**；macOS Gatekeeper 可能阻止首次打开；以文件名及本机芯片架构确认兼容性 |

每个平台提供独立的校验文件：`SHA256SUMS-linux.txt`、`SHA256SUMS-win32.txt`、`SHA256SUMS-darwin.txt`。请从本项目 **GitHub Releases** 下载安装包与校验文件，校验 SHA-256；哈希匹配只能验证内容一致，**不能替代发行者代码签名**。不要使用来源不明的镜像安装包。

v0.1.5 Linux Early Access 是之前仅有 Linux 安装包的公开预览版本；v0.1.6 作为新版本发布，不覆盖或删除 v0.1.5 的文件及版本标签。

## 功能范围

- 英语短句学习、系统 TTS 语音示范、正常/慢速播放、录音回听、收藏/复习/历史，以及本机存储。
- 英文/中文界面，Nordic 和 Sunset 双主题、窗口响应式布局及减少动画设置。
- **Linux x64**：默认本地英语实时听写引擎为 **Moonshine Voice Medium Streaming**。用户必须主动进入「离线模型管理」点击安装，首次需要网络和可用的 Python 3 + venv、可安装的原生依赖。下载模型及 Python SDK 后，应用检查 SDK 版本和固定模型 SHA-256，识别在本机完成。模型不随安装包内置（安装包本身**不内置**模型或原生 SDK）；缺失或校验失败不会静默切回 Zipformer。
- **Windows / macOS**：这次提供了安装包和基础英语练习、录音回听等功能。**未承诺 Moonshine 模型管理或同等本地实时听写已在这两个平台可用**。如相关能力不可用，基础学习功能仍可使用，不会生成伪造的听写结果。
- 没有自动发音评分、音素级纠音或经人工审核的真人配音。参考语音由设备的 TTS 引擎提供，声音质量与离线能力依赖系统语音包。

## 发布验证和仍未完成的验收

GitHub Actions 在 Linux / Windows / macOS 上构建、测试、检查真实安装包文件并生成各平台 SHA-256 清单，Linux 额外通过 apt 实际安装验证。此前的 Moonshine 模型与打包 Electron 推理测试使用的是**合成的英语测试 WAV**。已有 Linux 本机试用反馈，但**不能由此推断所有用户设备、噪声环境、口音和长期运行条件已经通过质量验收**。

尚未完成或不能视为已认证：Windows/macOS 上实体设备的全面麦克风与权限测试、跨设备可访问性复核、安装包签名与 Apple 公证、第三方依赖及内容授权人工复核、首批课程内容语言审校、F001–F012 的逐项验收记录、至少 5 位初学者的测试签收。因此本版本仅为自愿使用的 Early Access。

## 升级与反馈

同一平台上通常可直接安装新版本升级，不必卸载旧版本或删除历史数据。Linux 的个人 Moonshine 模型存储于用户配置目录，升级应用并不会自动删除或重新下载它。安装失败时保留系统和安装包版本、操作步骤与**脱敏**错误信息，不要上传私人录音或设备序列号。
