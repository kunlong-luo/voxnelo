# Voxnelo v1.0.2 — 官方正式维护版本（免签名）

> **这是正式补丁更新，不是 Beta。所有 Linux/Windows/macOS 安装包均未签名，macOS 未公证。** Windows SmartScreen / Smart App Control 与 macOS Gatekeeper 可能弹出警告甚至阻止安装。SHA-256 验证文件完整性，**不证明发布者身份或第三方安全认证**。

## 本次更新（自 v1.0.1）

1. **模型选择正确性（#163）：** 听写启动前再次校验用户当前选择的离线引擎，明确区分 Moonshine 缺失、旧 Zipformer 可用、模型/原生组件失效，避免误用错误引擎；Linux 不会擅自回退 Zipformer。
2. **可靠的质量评测（#164）：** 个人 Linux Moonshine 可独立批测 `--moonshine-only`，按 `quiet`、`external-playback`（另一台设备外放英语）、`noise` 分类计算加权 WER 与 RTF；本工具**不会**自动上传原始 WAV、完整字幕或真实用户录音，也不代表准确率已经提高。
3. **长期运行清理（#165）：** 每轮实时听写完成、取消或失败均移除 Electron 窗口生命周期监听器，阻止反复开始/停止后的资源累积；CI 增加 25 轮循环检测。
4. **Moonshine 通信稳定性（#166、#167）：** Python 多线程识别回调以不可交错的完整 JSONL 事件输出；本地 Python 提前关闭音频输入或 Stop 管道出错时报告受控失败，避免进程异常导致桌面线程出现未处理错误。回归覆盖 240 条并发事件和实际子进程异常。
5. 应用、五个工作区包、内部版本常量及 Linux AppStream 版本号统一到 1.0.2。不会删除、迁移或覆盖已有学习记录、收藏、个人离线模型及其安装目录。

## 能力边界与尚未完成

- Linux x64 的默认听写引擎为 Moonshine Medium Streaming。**模型不随安装包内置**；用户须在独立离线模型管理页主动下载并验证 Python SDK 和模型。首次安装需要网络，识别阶段默认在本机离线，不上传麦克风语音。
- Windows/macOS 继续提供本地学习、示范 TTS、录音回听、收藏和历史等基础功能；**暂不保证 Windows/macOS 具有与 Linux 同等的原生 Moonshine 实时听写**。没有虚拟识别成绩或自动发音评分。
- CI 验证包括 TypeScript、单元测试、Linux/Windows/macOS 原生构建、Linux DEB 实际 apt 安装、SHA-256 清单与 pinned Moonshine 合成语音集成；这些均**不能替代**跨系统真实麦克风测试。
- **尚未完成**至少 20 条真实参考语音在近讲、外放、口音和噪声下的配对 WER、RTF 与字幕延迟验收；F001–F012 真实设备门禁、教学内容/IPA 和第三方权利审查、五位目标初学者独立测试仍未全部完成。
- 已发布的 v1.0.0、v1.0.1 和其他历史发行不会被覆盖。签名与公证是发行者明确暂不采用的可选增强门禁，不应把本次官方免签名发行误称为第三方认证。
