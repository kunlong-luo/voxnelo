> **公开正式版本，不标记为 beta/prerelease。所有安装包未签名，macOS 未经过 Apple 公证。**
> “正式”仅表示维护者决定公开发行本次基础桌面版本，**不代表**软件已取得外部安全认证、全硬件认证或内容版权/教学审校结论。

## 实际实现
- 40 条基础英语口语练习短句，原文/中文/音标/分类，以及标注为**待审校预览**的扩充内容。
- 系统文本转语音（TTS）示范、正常/慢速播放；录音、停止与本次练习回听，切句清理。
- 本地 IndexedDB 学习历史、收藏、复习标记；中文/英文 UI、Nordic/Sunset 主题、响应式和减少动效。
- Linux x64 默认离线识别首选 Moonshine Medium Streaming（需要用户自行在模型管理页**主动授权并下载安装** Python SDK 与模型；首次联网，之后可离线）。**模型不随安装包内置**，无未经审核的第三方模型随安装包分发。
- Windows/macOS 提供基础桌面练习及录音回听；**不承诺**与 Linux 相同的本地 Moonshine 实时听写。没有自动发音评分或逐词纠错。

## 基于最新 main 的发行修复
- Linux 选定离线引擎不会因为模型列表刷新而被自动覆盖；并发旧请求不会覆盖新模型状态（#153）。
- 依赖、Windows/macOS/Linux CI、录音权限竞态处理、桌面应用启动/持久化/缩放回归、安全审计和 Linux DEB 实装检查均纳入验证。
- 已完成的一次性发布流程永久退役，避免 Dependabot 更新误发相同版本（#154）。

## 尚未完成或没有声称完成的核验
- **未签名/未公证**为维护者确认接受的发行限制；无法保证 Windows/macOS 所有安全策略下均能安装。
- 仓库中 F001–F012 真机签收台账、40 条教学文本与 IPA/系统 TTS 适配审校、至少 5 位初学者任务验收目前没有完整独立证据，不得虚称已全部通过。
- Moonshine SDK/模型需要用户在自己的设备上主动安装；噪声下 WER、10 分钟长会话、不同麦克风、架构/ABI 和来源许可仍需逐项复核。**不会公开捆绑未批准的离线引擎/模型**。
- macOS 安装包仅 ARM64，Windows x64，Linux x64；跨设备表现及隐私/法律专业审核仍需改进。
