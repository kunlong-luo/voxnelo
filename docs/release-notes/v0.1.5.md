# Voxnelo 0.1.5 — Early Access 候选说明

> **本次版本是未完成实机与内容授权验收的候选构建。** 如果 GitHub Release 仍处于 Draft 状态，请勿对外宣传为已发布的稳定版本。

## 目前已实现

- 40 条英语短句与中英文释义、场景、难度及 IPA 显示。
- 调用系统英语 TTS 的参考朗读、慢速与重播。
- 主动授权后的跟读录音、停止与本次回听，以及自由切句。
- 本地学习历史、收藏、复习标记和句子浏览。
- 中文/英文界面、北欧/日落主题及减少动效设置。
- Linux 安装包改进：包含 AppStream 品牌资料及软件中心图标；额外提供与标准 DEB 字节完全一致的 `Voxnelo.deb`，用于正确显示 KDE Discover 本地预览标题。

## 已知限制

- 标准安装包**不自带离线实时英语识别模型**。Linux 用户可另行选择个人内测引擎，但识别准确率与降噪尚未通过正式实机验收。
- 不包含 AI 发音评分、词级纠错或已审核的专业配音；参考朗读依赖操作系统已安装的英语语音引擎。
- Windows / macOS 安装器未签名或公证。发行前仍需对应系统的实机验证。
- 首批内容的语言审校、素材/语音授权、F001–F012 核心验收和目标学习者测试尚未全部完成；未取得发布批准前保持 **Draft**，不得公开宣布正式上线。

## 安全与隐私

Voxnelo 无需账户；学习记录保存在当前设备上。用户主动录制的音频默认仅供当前练习临时回听，不上传到 Voxnelo 服务。
