# Voxnelo v0.1.5 — Linux Early Access

> **公开预览版（Early Access）· Linux x64 · 未签名**。这不是稳定版或已完成全部平台认证的正式商业发行。用户已反馈 Linux 功能测试可用；仍需要更多独立设备、不同环境和学习者反馈，持续处理已知限制。

## 新增与改进

- **Linux 默认离线英语实时听写：Moonshine Voice Medium Streaming。** 在“离线模型管理”中明确点击安装，才会创建用户专属 Python 环境、下载英语模型并校验模型文件。没有自动退回 Zipformer，也不会在未验证模型时显示伪造的识别结果。
- 16 kHz PCM 本机识别、临时/最终字幕事件，具备进程隔离、音频积压保护、停止和取消时的资源释放。字幕历史与工作线程消息经过限长和验证。
- 40 条英语短句、中英释义、可选 IPA；使用系统英语 TTS 听读/慢速播放；跟读录音、停止、回听、收藏、复习、历史与本地离线记录。
- Nordic / Sunset 双主题，中英文界面与桌面适配。
- DEB 中的 AppStream 品牌元数据、Voxnelo 图标和字体依赖完善；`Voxnelo.deb` 与标准版本文件内容完全相同，便于 KDE Discover 识别本地安装包。

## 下载与安装

发布页面提供 **Linux x64** 安装包：

- `Voxnelo.deb` — Debian/Ubuntu/Pop!_OS 推荐的友好文件名。
- `voxnelo_0.1.5_amd64.deb` — 与上面完全相同的标准 DEB。
- `Voxnelo-0.1.5.AppImage` — Linux AppImage；运行时可能需要发行版依赖。
- `SHA256SUMS-linux.txt` — 以上三个文件的 SHA-256 校验和。

已有 Voxnelo 安装通常可直接升级，不必先卸载或删除个人学习记录。在 Debian 系列系统上，可通过软件包管理器安装 DEB 并解析系统依赖。

**首次启用实时听写**：打开 Voxnelo → **离线模型管理** → **安装 Moonshine 离线识别模型**。初次安装需要网络、Python 3 及其 venv 模块、可用磁盘空间和 Linux x64 原生 wheel 环境。模型及 SDK 下载完成、完整哈希通过后，识别在本地运行；模型不随安装包内置，也不保证初装时无网络即可识别。

## 已知限制与重要说明

- **未签名**：这是可公开试用的 Linux Early Access 包，不是经代码签名/公证的稳定安装器。验证安装文件的 SHA-256 可发现传输损坏，但不能替代发行者数字签名。
- **仅发布 Linux 安装包**：Windows/macOS 虽有 CI 打包产物，但没有作为这个 Release 的正式下载，也没有宣称完成跨平台真实设备验收。
- **准确率与性能**：真实 Moonshine 在合成英语 WAV 的 CI 和打包版 Electron PCM 链路上通过；它不能证明不同口音、噪声、扬声器播放或所有麦克风设备的准确率及字幕首字延迟均达标。
- **教学内容审校与第三方许可**：首批 40 句的教学质量、语言/音标和来源台账尚未全部签署；首次发布不提供经审核的专业真人配音。参考朗读依赖本机 TTS。项目代码采用 MIT，第三方原生运行时、模型和本机 TTS 可能有独立许可。
- **尚未完成完整 V0.1 验收**：F001–F012 的逐项跨设备人工验收、5 位初学者研究、视觉设计逐屏核对、隐私与品牌发布审查仍在继续。本版本是自愿试用的预览版，不应表述为全部质量门槛均已通过。
- **隐私**：Voxnelo 无需账号，英语本地识别不需要将麦克风音频发送至 Voxnelo 服务器。录音仅用于当前练习的临时回听；浏览器独立运行时的 Web Speech 服务可能适用其他平台政策。
