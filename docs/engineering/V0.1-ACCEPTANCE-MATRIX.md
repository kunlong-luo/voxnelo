## 端到端 P0 必测场景
- [ ] 首次打开，无账户直接听到当前短句参考示范。
- [ ] 明确授权后录音跟读、停止、回听最新一次录音。
- [ ] 拒绝麦克风权限仍可播放、换句、收藏。
- [ ] 示范播放时换句立即停止旧音频；不能播放上一句的录音。
- [ ] 关闭重启后历史和收藏存在，“仅浏览”不算“已完成练习”。
- [ ] 鼠标与键盘操作、窗口缩放、离线基础学习可用。
- [ ] 不呈现虚假 AI 评分、自动词级识别或纠音效果。

## 发布前的额外证据（CI 无法替代）
- [ ] 主要目标桌面平台上真实输入设备与权限/断开/休眠恢复已验证。
- [ ] 需要公开支持的平台安装包经过对应系统实测；签名/公证限制已说明。
- [ ] 录音未授权时不上传/不持久化，隐私说明与实际一致。
- [ ] 首批内容与参考音频来源、版权许可、教学质量已核对。
- [ ] 品牌/域名使用风险已处理，README 和已知限制准确。
- [ ] 至少 5 位目标初学者按路线图 Gate B 做过端到端任务验收，并记录阻碍。

## PR/验收证据填写格式
`F-ID | 测试平台/设备 | 手段 | 预期 | 实际 | 证据链接/日志 | 问题单 | 审核人/日期`
