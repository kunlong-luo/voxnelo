## 当前核对中需要进一步验证的风险

1. **F004 / F005**：已增加针对切句时主动释放麦克风、权限晚到、旧 `ondataavailable` / `onstop` 与新录音并发的模拟回归用例（`tests/use-recorder.test.tsx`），并在 `clearAudio` 中显式停止旧录音。**这仍属于代码级验证**，需要真实麦克风和发行包端到端实测才能关闭发布验收。
2. **F006 / F007 / F008 / F009**：除 fake-indexeddb 单元测试外，新增 `scripts/check-electron-persistence.mts` 及主 CI 门禁：在真实 Linux Electron `voxnelo:` origin，通过正式 UI 进行收藏、复习标记及换句，关闭整个 Electron 进程后使用同一临时用户数据目录重新启动，验证 IndexedDB 和收藏／复习列表，并确认仅浏览不计练习。**仍需 Windows/macOS 发行安装包真实设备验证**，不要据此把验收矩阵标为全面通过。
3. **F010**：40 句数量落在要求的 30–50 范围内，然而源文件明确标注 IPA 上线前需人工复核，不能以数量满足代替内容审核。
4. **F003**：系统 TTS/桌面回退路径不能被宣传为经过人工审核的专业参考录音。离线表现需按桌面平台确认。
5. **F011**：测试覆盖一部分安全判定，但隐私与 IPC 需要发行包动态审核；不应因静态测试通过便宣称不存在隐私风险。

## 推荐执行顺序

- **P0-A**：运行并核对现有 GitHub CI；记录通过/失败证据。
- **P0-B**：执行并核对 F004/F005 的异步回调与切句竞争回归测试，持续修复复现缺陷。
- **P0-C**：完成 F001–F012 的桌面实机端到端验收，更新状态与证据。
- **P0-D**：完成内容授权、IPA 校对、品牌/隐私与目标发行平台验收。
- **发布判定**：只有 [验收矩阵](./V0.1-ACCEPTANCE-MATRIX.md) 所列 P0 阻断项解除且有证据，才能推荐发布 Early Access。

本索引不要求引入 AI 实时识别/自由对话；这些能力不属于 V0.1 范围。
