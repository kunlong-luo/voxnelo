## 当前核对中需要进一步验证的风险

1. **F004 / F005**：`useRecorder.ts` 在停止录音和媒体事件回调之间存在异步时序；现有模拟测试覆盖基本录音、拒绝授权、录音中断和卸载后获得权限，但并不能证明所有切句竞争条件都安全。补针对“迟到的 onstop/ondataavailable、快速切句”的回归测试后再认定完成。
2. **F006 / F009**：当前测试使用 fake-indexeddb；它能验证业务持久化语义，不等于桌面正式发行包实际关闭/重启后的持久化验证。
3. **F010**：40 句数量落在要求的 30–50 范围内，然而源文件明确标注 IPA 上线前需人工复核，不能以数量满足代替内容审核。
4. **F003**：系统 TTS/桌面回退路径不能被宣传为经过人工审核的专业参考录音。离线表现需按桌面平台确认。
5. **F011**：测试覆盖一部分安全判定，但隐私与 IPC 需要发行包动态审核；不应因静态测试通过便宣称不存在隐私风险。

## 推荐执行顺序

- **P0-A**：运行并核对现有 GitHub CI；记录通过/失败证据。
- **P0-B**：补 F004/F005 的异步回调与切句竞争测试，修复真实复现问题。
- **P0-C**：完成 F001–F012 的桌面实机端到端验收，更新状态与证据。
- **P0-D**：完成内容授权、IPA 校对、品牌/隐私与目标发行平台验收。
- **发布判定**：只有 [验收矩阵](./V0.1-ACCEPTANCE-MATRIX.md) 所列 P0 阻断项解除且有证据，才能推荐发布 Early Access。

本索引不要求引入 AI 实时识别/自由对话；这些能力不属于 V0.1 范围。
