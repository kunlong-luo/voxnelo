## Follow-up — 2026-11-22

The [module reachability audit](../audits/2026-11-22-MODULE-REACHABILITY.md) adds an optional, read-only TypeScript import graph seeded from the actual Rsbuild/esbuild bundle entrypoints, including both ASR Workers and AudioWorklet. It distinguishes runtime, tooling and test-only references and explicitly flags unresolved dynamic imports. It does **not** certify unused symbols, CSS rules, IPC strings or packaged native resources, and must not auto-delete files. Any reported candidate remains open technical debt until separately proven safe.

## Definition of done

A debt item closes only with linked code/doc change, relevant automated checks, and any necessary independent manual evidence. Do not close acoustic, legal, privacy or accessibility gates based solely on CI.
