# Voxnelo V0.1 — Release Candidate 操作与验收手册

> 依据冻结版 `docs/Voxnelo-Product-Docs-v1.0/docs/08-测试验收与发布.md`。本手册用于生成**未签名的内部测试候选包**，不是正式公开发布授权。所有 F001–F012 P0 项必须在 `V0.1-ACCEPTANCE-MATRIX.md` 中留下真实证据。

## A. 生成三个平台的候选安装包

1. 先确认 `main` 的 CI 完整通过，且无未合并的发布修复 PR。
2. 在 GitHub 仓库 **Actions → Desktop release candidate → Run workflow**，选择 `main` 运行 `workflow_dispatch`。尚未完成发布门禁前**不要创建正式的 `v0.1.0` tag**。
3. 检查 Linux（`--linux deb AppImage`）、Windows（`--win nsis`）、macOS（`--mac dmg`）三个 job 均通过。
4. 下载该次 workflow 的 `voxnelo-linux-unsigned`、`voxnelo-windows-unsigned`、`voxnelo-mac-unsigned` artifacts，并记录 Run URL、工作流提交 SHA、安装包文件名、SHA-256 和测试日期。
5. 工作流会检查正式候选安装包文件，而不是只验证解包文件：Linux `.deb` / `.AppImage`，Windows NSIS `.exe`，macOS UDIF `.dmg`。它们尚未签名或公证，不自动发布 GitHub Release。

**注意**：GitHub Actions 产物默认只保存 14 天；若需要长期留档，应由仓库维护者在受控位置保存 SHA-256 和适当权限的测试包。

## Linux 中文字符显示验收（新增）

如果安装后中文显示成方框、空白或乱码，先区分：
- **应用界面文字（English 正常、中文变成方框）**：一般是系统缺少 CJK 字体。Debian/Ubuntu 的新 `.deb` 已将 `fonts-noto-cjk` 设为软件包依赖（保留 electron-builder 默认依赖）。用 `sudo apt install ./Voxnelo-*.deb` 安装，以便 apt 自动解析字体依赖；已有安装可用 `sudo apt install fonts-noto-cjk`，然后彻底重启 Voxnelo。若仍有问题，检查 `fc-match 'sans:lang=zh-cn'`。
- **AppImage**：不经过 Debian 包管理，无法自动安装该依赖。在 Debian/Ubuntu 上手动安装 `fonts-noto-cjk`；其他发行版需使用其官方软件源提供的等效 CJK 字体。此项在系统无 CJK 字体的 AppImage 上仍需实机验证。
- **英文、窗口装饰或安装器本身也乱码**：不一定是中文字体问题，应同时收集操作系统发行版、软件包类型、安装器截图、Voxnelo 窗口截图及 `locale` 和 `fc-match` 输出，排查字符编码/字体回退或安装器界面故障，不要直接宣称字体依赖已解决全部乱码。

复测时必须分别覆盖 `.deb` 和 `.AppImage` 的中英双语、标点符号与教学句子（包括新增素材库），并保留证据。

## C. 核心闭环验收（F003–F005）

1. 新安装、无需账号进入单句练习，播放当前句英语示范；慢速、正常与重播均有实际声音，系统无英语语音包时必须给出可理解的提示。
2. 明确授权麦克风，点击录音按钮开始，再点击**同一个按钮**停止，回听到最新一次声音；在尚未录制成功时不能显示假的可播放音频。
3. 录制三次，最后回听的必须是最后一次；播放回听时换句，旧音频必须停止；换句后不应提供上一句的回听。
4. 拒绝麦克风权限或拔掉设备仍能浏览、播放、收藏和换句，不崩溃、不误报成功。
5. 关闭重启后历史/收藏/复习标记仍存在，只有浏览的句子不会被算为已录音练习。
6. 禁用网络后仍可打开本地课程与历史。系统语音服务依赖具体平台，不能把未验证的 TTS 宣传成“所有平台离线专业录音”。

## D. 公开发布前的人工门禁

- [ ] F001–F012 逐条有平台、操作、预期、实际、截图/日志、责任人和日期的验收记录。
- [ ] `V0.1-CONTENT-REVIEW.md` 中全部 40 句的英文、中文、美式 IPA、参考音频来源和分发权由合适人员审核签署。
- [ ] 产品品牌/商标、隐私说明、问题反馈及安装/卸载/更新文档经过核对。
- [ ] 真实麦克风与离线操作在主要目标平台完成测试，安全告警与未签名限制充分披露。
- [ ] 至少 5 位目标初学者独立完成核心流程，记录阻碍及修复。
- [ ] 如默认安装包没有已验证的本地 ASR 引擎，不能宣称桌面实时听写开箱即用；不得伪造识别内容或开启未经许可的云音频上传。

只有完成这些条件，才可考虑 `v0.1.0` 的公开 Early Access 发布。候选包用于内部验收，不表示以上门禁已被解除。
