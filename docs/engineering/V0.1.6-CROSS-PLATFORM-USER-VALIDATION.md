# Voxnelo 跨平台用户试用反馈（v0.1.6）

记录日期：2026-10-22

## 已得到的反馈

用户明确表示：**“已经验证过了，各个平台都可以用。”**

因此，Linux、Windows、macOS **基础应用可用性**具有直接的用户试用反馈。后续开发不得继续将“三个平台尚未有人测试能否打开和使用”当作未经核实的阻塞。

## 不从这一句反馈推断的结论

用户没有提供各平台的详细机型、操作系统版本、测试用例或日志。这份反馈本身**不能**证明：

- Windows/macOS 已具备与 Linux 相同的 Moonshine Medium Streaming 本地推理能力；
- 所有平台的实时字幕 WER、首字延迟、后台噪声和长期运行均已通过定量验收；
- 包含 Intel Mac 在内的所有硬件架构均已覆盖；
- 未签名发行包具备操作系统的可信签名/Apple 公证；
- F001–F012 的逐项验收、第三方依赖许可和内容审校全部签署。

## 后续工作规则

- 接受并保留已收到的跨平台基础使用反馈，不再重复要求用户证明应用是否能运行。
- 将余下 Issue 聚焦**具体尚未测试或尚未达到的能力**，例如 Moonshine 原生跨平台支持、模型安装修复、安全签名、教学素材审校。
- 新的回归报告须包含平台、版本、功能和结果，避免把“能用”与“完整符合 Stable 条件”混淆。
