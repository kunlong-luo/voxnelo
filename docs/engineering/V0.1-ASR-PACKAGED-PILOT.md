## 本 PR 的新增阶段

在 Linux CI 的临时目录调用 `scripts/stage-asr-pilot.mts`：从独立的 npm package 安装目录复制经固定版本安装的真正原生依赖和锁定的模型文件，保留所有 native package 相对路径，计算所有文件 SHA-256 并写入清单。再运行：

1. `scripts/check-asr-staging.mts`，检查清单文件与真实字节一致。
2. 使用**重新定位后的 native/index.cjs + 模型目录**进行真正 WAV 识别；不使用 Mock。
3. Linux Electron 安装包构建与 `scripts/check-desktop-package.mts`，验证 build 到 resources 中的文件完整性。

这个阶段产生的候选标记 `releaseReady:false`。其原生组件及模型文件**仅存在于 CI 临时工作目录，不能上传公开可下载的含原生文件安装包**。`scripts/check-asr-real-release.mts` 明确拒绝把 `releaseReady:false` 作为正式发布版本。CI 成功不能替代真实设备上的 Electron ABI/麦克风与持续识别测试。
