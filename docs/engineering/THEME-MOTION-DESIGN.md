# Voxnelo · 双主题视觉与动效实施规范（Early Access）

本文件记录实际代码中使用的主题语义，补充而不修改冻结的 V0.1 PRD（F001–F012）。

## Warm Sunset Glassmorphic（默认）
- 应用画布：`linear-gradient(135deg,#F8DEC5 0%,#E8D3C7 50%,#D8C3B9 100%)`
- 主练习玻璃：`rgba(255,255,255,.4)`，背板 `blur(20px)`，1px `rgba(255,255,255,.6)` 边缘高光
- 阴影：`0 24px 60px rgba(180,140,120,.2)` 及顶部内高光
- 英文主句 `#1A202C`；中文 `#4A5568`；音标 `#718096`
- 主麦克风渐变 `#DD6B20` → `#ED8936`；装饰波纹自橙 `#DD6B20` 至薄荷青 `#38B2AC`

## Nordic Minimalist
- 画布 `#F7F8F5`；侧栏 `#E8F0EA`；卡片白色；弱表面 `#F0F4F1`
- 英文主句 `#243B46`；中文 `#5A717B`；音标 `#8FA2A9`
- 核心渐变 `#477F83` → `#A6C5BA`；波纹 `#A6C5BA`；暖色点缀 `#E29578`
- 卡片为纸质纯色表面，不应用 20px 玻璃模糊，主要依靠留白与字体建立层级

## 设计工程原则
- Tailwind CSS v4 实现组件样式；`design-system.css` 只放 token、基底、动画定义与滚动条。禁止额外零碎全局样式。
- 启动默认动画预览，独立于操作系统的减少动画偏好；在「设置 → 动态效果预览」可一键关闭。该选择仅本地保存，不影响语音或课程内容。
- 大面积光晕仅使用变换和透明度变化，避免无限重绘渐变或让整张卡片跳动。没有频闪。
- 波纹只表示平静的视觉节奏，**不是 VAD、麦克风音量或 ASR 识别结果**。
- 状态色：准备就绪为轻微呼吸，真正监听中增强外环脉冲，真实录音完成且可回放时才显示一次柔和完成光效。没有识别引擎时不得冒充正在监听。
- 320×640、800×610、1160×760、1440×900 及 125%/150% DPI 必须保持主操作可点击、无水平溢出。
- GitHub CI 在实际 Chromium 验证动画不是仅有 class 名：要求 `getAnimations()` 运行且时间确实前进；手动关闭时动画应停止。
