# 12｜工程实施与交付边界（2026-10-15）

## 当前确认

- 产品：Voxnelo（中文名“声语跃动”仅为工作候选）。
- 平台：Windows / macOS / Linux **桌面优先**；Web 为共享渲染入口；Android / iOS 是后续路线。
- 语言：第一阶段中文引导学英语，未来预留英语引导学普通话。
- V0.1：听示范、录音回听、换一句、收藏、复习与历史。
- V0.9：内部评估三大功能的可靠性。
- V1.0：经过测试后公开 SpeakFeed、Speak Karaoke、Smart Prompt；音素级纠错只在评估通过时发布。

## 技术决策

- React 19.3 + TypeScript + Rsbuild/Rspack + Tailwind CSS 4；Electron 容器；Dexie / IndexedDB 学习记录。
- V0.1 无强制云服务和付费 API；参考朗读暂用本地系统 TTS。
- 未来 ASR/AI 接口保留独立能力边界，但不为了未实现的功能创建大量空包。
- 浏览、朗读尝试和掌握度是不同事件，**不使用“看过”冒充“会说”**。

## 不属于当前交付

本项目包没有执行用户本机安装、创建远程 GitHub 仓库或发布安装包。依赖安装与构建已在开发机验证通过（node_modules、pnpm-lock.yaml 俱在；`pnpm typecheck` / `pnpm test` / `pnpm build` 均已通过，产物为 dist/ 与 dist-electron/），但尚未产出 release/ 安装包，实机验收仍未完成。源码通过静态内容检查后可在目标电脑按 README.DEVELOPMENT.md 操作。
