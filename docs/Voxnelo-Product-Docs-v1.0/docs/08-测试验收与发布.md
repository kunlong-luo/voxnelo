# 08｜测试、验收与市场发布

## 1. 核心测试结构

| 类型         | 验证重点                                     |
| ------------ | -------------------------------------------- |
| 内容单测     | 短句 ID、标签、翻译、关联音频与数据结构合法  |
| 学习逻辑单测 | 浏览/听过/尝试/自评状态不会串改              |
| 存储单测     | 历史、收藏、备份、迁移、异常恢复             |
| UI 自动化    | 播放、换句、录音授权提示、返回历史           |
| 实机录音     | 麦克风权限、输入设备、录制格式、系统休眠恢复 |
| 可访问性     | 键盘、焦点、对比度、减少动态效果、字号缩放   |
| 真实学习者   | 独立开始、能否理解、是否愿意继续练习         |

## 2. V0.1 发布阻断条件（必须全部解决）

- 使用主要目标桌面系统，完整跑通一次真实麦克风跟读回放。
- 播放和录音不会在切句后残留到下一句。
- 关闭/重开后，历史收藏仍完整。
- 录音授权拒绝和麦克风断开有明确提示，不崩溃。
- 未经许可不保留原始音频、不上传录音。
- 首批内容的版权/音频授权明确。
- 不出现虚假的 AI 发音分数、词级跟踪及误导性描述。
- 发行包经过平台实测，无阻断性安全问题。

## 3. 桌面平台发布包

- **Windows**：`.exe` 安装包，Windows 11 实机验收。
- **macOS**：`.dmg` 或 `.pkg`，需 macOS 构建环境，考虑签名/公证及麦克风权限。
- **Ubuntu/Debian**：`.deb`，用户可通过 `sudo apt install ./<package>.deb` 本地安装。
- **其他 Linux**：按需 AppImage；真实发行版和桌面会话（包括 X11/Wayland）需验证。

跨平台工程不意味着一台机器上就能可靠完成所有系统的正式签名/打包。推荐 CI 对应系统 runner，实机完成音频验收。

## 4. V1.0 三大特色技术验收

### SpeakFeed

- 一次触控板/滚轮滑动只触发预期的一次切句。
- 上下方向固定，上=下一句，下=上一句；有键盘/按钮后备。
- 中断中的录音/提示不泄漏到下一句。

### Speak Karaoke

- 读半句不点亮全句。
- 停顿后不自动判错，重复词不乱跳。
- 临时识别结果变化时无明显高亮抖动。
- 系统示范音不会被误识别成用户声音。
- 非确定结果不会标成“发音正确”。

### Smart Prompt

- 关闭后不会主动播放提示。
- 开启后只有真实停顿且有可靠当前位置才触发。
- 用户重新讲话时不插话，同词最多自动提醒一次。
- 提示音频不能替用户完成单词。

## 5. 产品验证指标（初期指标是目标，不是现有事实）

| 指标            | 测量方式                    | 建议初始判断             |
| --------------- | --------------------------- | ------------------------ |
| 首次任务成功率  | 测试者独立完成听/录/回听    | 目标 ≥ 80%               |
| 首次到成功开口  | 观察中位时间和卡点          | 逐版减少步骤             |
| 7 日内回访      | 自愿参与者匿名反馈/本地日志 | 观察趋势，不预设虚假数字 |
| 复练率          | 再次录音的句子占比          | 用于判断学习而非纯浏览   |
| 麦克风异常率    | 设备层异常/录音尝试         | 持续降低                 |
| V1.0 识别错位率 | 人工对照短句音频与高亮      | 内测设阈值后才能开放     |
| 自动接话误触发  | 用户实际在说话却插入提示    | 内测达标前不开放         |

隐私原则：不以不透明的远程音频上传作为埋点前提。优先采用本地统计、主动用户反馈与匿名汇总。

## 6. 上线步骤

1. 锁定品牌可用性、内容授权与技术版本。
2. 创建测试发布渠道，仅邀请小范围试用。
3. 执行自动化和真实设备录音验证。
4. 写清楚功能边界、已知平台限制和隐私政策。
5. 发布桌面 Early Access，记录问题和改进优先级。
6. 根据真实用户练习与回访结果决定 V0.2/0.3 投入。
7. V0.9 内部测三大特色，质量达标再推出 V1.0。
