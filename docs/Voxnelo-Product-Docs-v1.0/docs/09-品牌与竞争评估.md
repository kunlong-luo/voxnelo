# 09｜品牌与市场竞争评估

> 本文总结此前讨论与初步公开信息，**不构成商标法律意见，也不宣称已完成最新全渠道排他检索**。品牌上线前应以目标地区的官方商标数据库及人工复核为准。

## 1. 当前工作名称

- **英文工作品牌**：Voxnelo。
- **中文候选**：声语跃动。
- **历史项目名**：SpeakSeed；因已经出现相近教育场景中的同名使用线索，不建议继续作为首选对外品牌。
- **推荐副标题（首发）**：英语口语陪练。
- **正式版副标题（具备实际 AI 能力后）**：AI 口语教练（不得先于功能宣传）。
- **建议口号**：从第一句开始，自信开口。

**品牌状态：未最终锁定。** Voxnelo、声语跃动都需要检查完全相同及近似名称、汉字音义相近、跨行业声音软件商标、域名/App Store/Google Play/GitHub 名称使用情况。

## 2. “加 AI”命名策略

正式商标建议保持短而独立：`Voxnelo`，不默认加 AI 后缀。AI 是能力而非产品唯一价值；V0.1 无 AI 功能时不能以 AI 教练宣传。V1.0 若真正实现可靠 AI 发音跟踪，可在描述语里使用“AI 口语教练”。

## 3. 竞争格局（需在上市时复核）

| 竞品类型            | 常见产品案例              | 已有能力                          | 我们的机会                                     |
| ------------------- | ------------------------- | --------------------------------- | ---------------------------------------------- |
| 发音评分 / 教练     | ELSA Speak、BoldVoice     | 录音评分、针对性纠音或 AI 练习    | 中文零基础易用性、免费核心练习、本地隐私       |
| 口语 AI 陪练        | Speak 等                  | 场景对话、生成式反馈              | 先练一句、不强迫自由对话                       |
| 朗读跟踪与卡壳辅助  | Google Read Along 等      | 跟读检测、阅读提示，部分免费/离线 | 成人实用口语、桌面场景、零基础中文引导         |
| 短句/短视频式语言流 | 市场已有语言刷卡/滑动工具 | 上下翻页、内容推荐                | 推荐与实际开口、历史复练结合，而不是单纯刷内容 |

**结论**：SpeakFeed 的上下滑本身容易复制；Speak Karaoke 的“真实词级跟读”也不是全球首创。最值得竞争的是**顺滑、可靠、低压力、可回溯且基础免费**的完整学习体验。

## 4. 初步目标受众和渠道

- 首批种子用户：中文英语零基础、希望练习口语的电脑使用者。
- 首发：GitHub Releases、开源社区、英语初学者社区，桌面安装包与简单演示视频。
- 优先看真实跟读次数、复练率和反馈，不靠“下载数”判断教学成功。
- 移动端未来更适合随时练口语，需在桌面阶段同步搜集是否需要手机的证据。

## 5. 品牌正式落地待办

1. 在 USPTO、WIPO、目标市场商标库检索英文完全同名、近似读音/拼写、相关教育和软件类别；中国市场另查国家知识产权局。
2. 逐一核查“声语跃动”中文商标及与“语言跳动”等现有名称的混淆风险。
3. 检查目标域名的当前注册状态；检索 GitHub 组织/仓库名及应用商店近似名称。
4. 在取得适当结论后，统一产品显示名称、软件包 ID、网站、开源仓库与 Logo。
5. 避免使用与已有“字节跳动/TikTok”相似的 Logo、商标元素或明显混淆性设计。

## 6. 正式宣传边界

- V0.1 可宣传：免费英语短句听读、录音回听、收藏、历史、桌面版。
- V0.1 不可宣传：AI 发音纠错、实时卡拉 OK 跟读、自动卡壳帮助、手机端已经上线。
- V1.0 仅宣传通过测试且真实可用的特色功能。
