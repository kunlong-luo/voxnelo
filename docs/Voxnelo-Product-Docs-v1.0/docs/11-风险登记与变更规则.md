# 11｜风险登记、发布限制和需求冻结规则

## 1. 主要风险登记

| 风险                   | 影响               | 优先应对                               |
| ---------------------- | ------------------ | -------------------------------------- |
| 品牌近似或已有商标     | 法律/营销返工      | 正式发布前商标与域名核验，名称暂用候选 |
| 音频素材无分发授权     | 无法合法发布       | 建立资源来源、授权清单，替换不合规内容 |
| Mac/Linux 麦克风兼容   | 用户无法跟读       | 系统权限与实机矩阵验收，不虚称全端稳定 |
| 录音/播放器切换竞态    | 串音、误保存       | 显式状态机、会话 ID、取消旧任务        |
| ASR 对零基础发音错位   | 绿色误点亮、挫败感 | V0.9 强制音频对照验证，低置信保持中性  |
| 自己播放的示范被识别   | 错误自动完成       | 分离播放与录制窗口、抑制扬声器回授     |
| Smart Prompt 误触发    | 打断用户思考或说话 | 可关闭、可调时间、语音活动与进度双判断 |
| 音素标红误判           | 误导学习者         | 专业评估独立上线条件，默认不显示       |
| 过度推荐与无尽刷动     | 用户只刷不练       | 结合待复习、按需结束、分开浏览与练习   |
| 中文模式直接套英语模型 | 声调/词组跟踪错误  | 独立中文内容、拼音和 ASR 验收          |
| 过早上移动端           | 拖慢桌面首发       | 保持移动方向但明确版本优先级           |
| “AI”标签过度承诺       | 失去信任           | 只有真实上线 AI 功能才使用描述语       |

## 2. 发布不可越过的红线

- 未真正识别用户声音时，不得自动把文字按时间变绿。
- 未经过专业发音评估时，不得说某个音素发错或标红。
- 用户关闭自动接话时，不能自动发出示范音。
- 录音/音频上传必须经过清楚告知和许可。
- 没有测试过的平台不能写“全面兼容”。
- 没有完成核验的名称不能声称“商标无冲突”。

## 3. 需求变更控制

任何新想法须回答四个问题：

1. 它解决真实用户的哪一个问题？
2. 它属于哪个版本？是否抢占当期 P0？
3. 需要哪些数据、音频、授权和权限？
4. 如何在真实设备上验收？

V0.1 的 P0 一旦锁定，新增功能默认为 V0.2+；只有阻断基础使用的缺陷可以进入当前版本。
