# 07｜语言教学与首批内容策略

## 1. 教学指导原则

- 英语小白不是先背完整 IPA 表再开口，而是先从生活里用得上的短句开始，遇到难音时局部解释音标。
- 先听 → 模仿 → 尝试独立说 → 自评/必要时重听。
- 句子尽可能简短、真实、适合口头说出，而不是书面化翻译句。
- 一节课围绕一条主要表达，不强行塞入大量语法术语。
- V0.1 中“完成练习”不代表已经真正掌握。

## 3. 内容数据要求

每句实际字段为：`id / english / chinese / ipa / topic / level`（见 `Sentence` 接口），
其中 `topic` 取 `greetings | personal | needs | learning | daily`，
`level` 取 `Pre-A1 | A1`。`referenceAudioId / targetAccent / tags / lessonVersion`
暂缓——V0.1 无授权音频资产，决策见 `docs/ADR/ADR-0001-reference-audio.md`。

`ipa` 为美式教学参考、尚未经人工语言学复核（代码侧已有同义注释），
发布前不得作为标准发音依据；不能在缺少可靠 IPA 校验时伪造音标字段。

慢速播放 V0.1 经系统 TTS 变速实现（0.75x）；引入授权音频后，慢速可通过音频变速
或另录慢速版本实现，但需要避免明显的变调失真。

## 4. 复习策略

- V0.1：最近练过、用户标记需要再练、收藏。
- V0.2：简化间隔复习，例如“需要练习”尽快出现，“熟悉”适当延后。
- V0.3：根据练习频次、复习到期与主动兴趣调整推荐；不需要 AI 生成内容。
- 真正的口语能力测量优先通过独立表达与真实对话任务，而非音频音量或浏览次数。

## 5. 从零基础到进阶的长期路线

- Pre-A1：发音听辨、简单问候、第一批高频句子。
- A1：介绍、需求、购物、时间、地点、简单问答。
- A2：讲述经历、计划、熟悉场景互动。
- B1：连贯表达原因、描述问题、简单讨论。
- B2：较流利的观点讨论、即兴应答。
- C1：深入讨论、语气和表达细微差别。

分级参考 CEFR 能力描述，不因完成若干句自动授予水平认证。

## 6. 外国用户学普通话

作为单独语言方向实施：英文指导 + 普通话示范 + 拼音声调 + 汉字词组跟读。英语与普通话课程共用学习会话、历史、收藏与内容流引擎；**声调判断必须独立验证**。未来可以按 `learningDirection` 分开学习记录。

## 7. 授权与内容合规

- 开源代码协议与课程/录音资源授权分开声明。
- 不直接抓取或打包商业词典音频、受保护的课程视频和教材。
- 每个音频资源记录授权来源与分发范围。
- 大模型生成的课程必须经过人工审核，不能直接发布为标准发音教学材料。
