# 01｜产品定位与关键决策

## 1. 产品愿景

让不会英语的中文用户无需复杂准备，就能从第一句开口，逐步建立正确的听辨、模仿和实际表达习惯。产品以口语学习效果为目标，而不是把无限刷句、AI 对话次数或签到数量作为目标。

**产品价值主张**：中文引导、极简操作、基础功能免费、本地优先、真实开口与可回溯的学习记录。

**对外 V0.1 定位**：免费英语听读与跟读练习。**对外 V1.0 定位（条件式）**：像刷短视频一样发现句子，像卡拉 OK 一样跟读，并在卡壳时获得可控帮助。

## 2. 核心用户

- 第一用户：中文母语、从零开始学英语口语；可能不认识音标，也不习惯英文菜单。
- 第二用户：认得单词，但不敢开口、听辨薄弱、容易在句中卡住的学习者。
- 未来用户：以英语等语言为母语、从零学习普通话的用户。该用户群需要独立内容、拼音与声调评估，不能简单交换翻译。

## 3. 被明确确认的决策

| 决策                                               | 状态                 |
| -------------------------------------------------- | -------------------- |
| 先桌面端，后移动端（未来必须有 Android / iOS）     | 锁定                 |
| 以 Web 技术共享核心代码，桌面 Electron 优先        | 锁定                 |
| 初始面向中文用户学英语；未来支持外国人学中文       | 锁定                 |

| 正式品牌 Voxnelo / 声语跃动                        | **未锁定，待核验**   |

## 4. 不可妥协的体验原则

1. 首次打开不要强制登录、付费或完成长问卷。
2. 每个界面只有一个优先操作；能一步完成不做两步。
3. 英语零基础用户可以只看中文理解“接下来做什么”。
4. 用户允许暂停、关闭录音和自主重练；不能在后台秘密监听。
5. **已浏览 ≠ 已跟读 ≠ 已完成 ≠ 已掌握**。
6. 不能因识别器听错，就把学习者的正常口音判红；无法评估时如实说明。
7. 动效为反馈服务，不能影响阅读、制造倒计时压力或刺激无尽刷动。
8. 课程内容与音频必须经审核、具有合法授权。

## 5. 明确不做（首发）

V0.1 不做：实时 ASR、整句染色、音素级纠错、自动接话、上下滑动信息流、AI 自由对话、账号与云同步、付费系统、排行榜、复杂考试题库、过量的语法教学。

## 6. 用户核心任务

**任务 A（首次）**：打开应用 → 看到简单句 → 一键听参考发音 → 一键录音 → 回听 → 换一句。

**任务 B（回访）**：打开应用 → 恢复上次学习位置 / 查看历史 → 收藏或复练薄弱句。

**任务 C（长期）**：在正式版中，听一句 → 按自己的节奏朗读 → 看到真实进度 → 卡壳时可选帮助 → 完成并积累。

## 7. 竞争策略

通用英语口语、发音评分、阅读跟读、短视频式语言卡片均已有市场参与者。我们不宣称“全球首创”。先以“中文零基础 + 可用的免费桌面跟读 + 极低交互负担”验证基础价值，随后以“稳定的真实跟读进度 + 温和可控的自动接话”优化体验。是否有可持续竞争力取决于用户复练率、识别误判率、内容质量和渠道，而不是动效是否漂亮。
