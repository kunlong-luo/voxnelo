# 04｜交互与微动效规范

## 1. 设计心智

**不是在考试，而是在练习说话。** 用户是零基础学习者，可能不会读英文，也不熟悉专业音标。界面用中文提示下一步，句子占视觉中心，操作尽可能减少。

### 桌面首版（V0.1）信息层级

1. **主内容**：英文句子，明显可读；中文释义在下方。
2. **主动作**：播放示范、录音/停止、回听；三个动作视觉层级明确。
3. **辅助动作**：换一句、收藏、历史、慢速。
4. **次级区域**：音标（默认按需展示）、复习标签、设置。

首版保留一个“换一句”按钮，**不出现沉浸式上下刷**，避免提前把 V1.0 的完整特色公开。

## 2. 关键流程

### 首次进入

应用打开 → 看见当前句 → 一键听示范 → 明确授权麦克风 → 录音 → 停止与回听 → 可收藏或换句。

### 无麦克风

提示“没有检测到麦克风，仍可听英语和收藏句子”。录音操作不可用但不隐藏原因。

### 中断

- 最小化、休眠、切换系统音频设备时，安全暂停录音或报告状态变化。
- 句子切换时停止旧音频，不允许“前一句还在播放”。
- 已提交的收藏/历史动作自动保存，不出现重复确认。

## 3. 微动效基线

| 场景     | V0.1                          | 版本 V1.0 增强                  |
| -------- | ----------------------------- | ------------------------------- |
| 按钮     | 轻微按压反馈（约 120–180ms）  | 保持简洁                        |
| 换一句   | 柔和淡入/位移（约 180–300ms） | 滑动切换 + 动画（约 250–400ms） |
| 录音中   | 真实状态灯和简洁真实音量条    | 精致波形，与 Speak Karaoke 联动 |
| 等待说话 | 静态友好提示                  | 轻微呼吸（约 2–3s 循环）        |
| 已读单词 | **无自动填色**                | 由真实识别结果驱动由左向右填绿  |
| 卡壳     | 可点重听                      | 自动定位当前词并可选提示        |
| 完成整句 | 不自动评分/不做虚假完成       | 单次柔和光泽，尊重减少动态设置  |

### 动画技术规则

- 尽量用 transform / opacity 等合成友好的属性。
- 波形用 Web Audio API + Canvas 或轻量绘制，与 React 状态更新解耦。
- 不使用突兀闪烁、频繁抖动、倒计时催促或持续 Loading 旋转。
- 尊重 `prefers-reduced-motion` / 系统减少动画设置。
- 焦点可见，动态效果不能成为唯一的反馈途径。

## 4. V1.0 SpeakFeed 滑动与桌面替代操作

- 向上滑：下一句；向下滑：上一句。
- 在桌面端同步支持触控板、滚轮（设防抖/节流）、方向键和屏幕可点击替代。
- 朗读录音过程中发生切换：安全结束/取消当前识别会话，保存已确认状态，停止上一句播放。
- 没有无限自动跳下一句的压力；提供自然暂停与结束入口。
- 推荐基于难度、近期练习、待复习、兴趣主题，不把刷过看成掌握。

## 5. V1.0 朗读交互与颜色语义

- 默认灰白：未读。
- 暖黄：正在检测/待确认，**不是错误**。
- 柔绿：当前识别逻辑确认用户已读到该词，**不是标准发音认证**。
- 柔红：仅用于发音评估可靠地定位的疑似问题，并明确提示“不确定时不标红”；未启用专业评估时不出现红色音素。
- 活动词可柔和呼吸，但不能影响上下文阅读。
- 临时识别结果可以改变：暂态高亮允许调整，稳定的已确认状态需要谨慎更新。

## 6. 智能接话的人因原则

- 用户主动可开启/关闭，零基础引导模式可建议默认开启，但必须清楚说明与持久保存设置。
- 预设 3 / 5 / 8 秒；初始建议 5 秒，仅在**没有语音活动且没有朗读进展**时计时。
- 正在讲话、音频尚未结束、麦克风短暂无声等情况不得直接判定卡壳。
- 触发后只播当前待读的下一个单词/小短语；同一个位置默认只自动提醒一次。
- 提示播放期间暂停/抑制 ASR 对系统音频的消费，避免系统自己把提示标成用户读过。
- 用户一重新开口，尽量停止排队的提示，避免抢话。
- 帮助之后用户必须自己说，系统示范不能替用户点绿。

## 7. 语音命令边界

V0.1 不要求语音控制。后续支持“再来一次、慢一点、暂停、继续”等短指令，必须避免与用户正在读的英语文本混淆；语音服务不可用时保留明显按钮。
