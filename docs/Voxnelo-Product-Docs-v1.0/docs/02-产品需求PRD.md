# 02｜完整产品需求 PRD

**版本**：1.0 冻结基线｜**工作品牌**：Voxnelo（待核验）｜**发布策略**：桌面 Early Access → 正式版三大特色。

## 1. 产品目标

使英语零基础中文用户在不阅读说明书的情况下，快速听懂目标句的意思、听到参考发音、完成一次录音跟读、回听自己的声音，并在下一次使用时无缝复习。

### 首发成功定义

陌生学习者可以在最小帮助下完成“听 → 跟读 → 回听 → 保存/换句”闭环；没有麦克风也可以继续听示范与浏览内容；失败状态不崩溃也不误报成功。

## 2. 优先级含义

- **P0**：缺少就不能发 V0.1；必须有实际验收。
- **P1**：V0.2/V0.3 改善学习和留存；V0.1 如有余力不抢 P0。
- **P2**：V0.9 内部研发或 V1.0 正式版功能；不提前公开。

### V0.1 操作约束

- 不显示 AI 分数，不自动把整句标绿。
- 麦克风只在用户明确开始练习后开启；结束后及时释放。
- 不要求语音识别才能开始练习。移动 Web/PWA 不是本版交付阻断项。
- 关闭应用再打开，优先恢复最后一条练习内容；允许快速换句。
- 不把单纯浏览视为学习完成；没有可靠自动评估时使用用户自评。

## 6. 语言方向与平台

- **V0.1**：中文界面，中国用户学美式英语；Windows/macOS/Linux 桌面目标，按实际构建环境逐一验证。
- **未来 Web**：同一 React 业务核心，可选发布 Web 版；录音需浏览器安全上下文和用户授权。
- **未来 Android / iOS**：移动端是长期明确方向，必须重新进行麦克风、模型、手势与发布测试，不应假定 Electron 直接产出移动包。
- **未来 Learn Mandarin**：外国用户学普通话需要拼音/声调、中文音频与独立课程，不简单交换语言字段。

## 7. 非功能性需求

- **隐私**：默认不上传/保存原始录音；若要云端处理必须明示并选择加入。
- **离线**：V0.1 基础课程、参考音频和学习历史可在离线状态运行；依赖系统 TTS 的辅助播报不做确定性离线承诺。
- **性能**：切换无明显卡顿；录音状态反馈及时；减少动态效果设置有效。
- **内容**：英文、中文、音频和音标一致；商用与开源授权明确。
- **安全**：Electron 启用上下文隔离、沙盒、受限 preload IPC，禁止任意脚本执行。
- **真实**：已完成、已掌握和发音正确是不同概念，不可混淆。

## 8. 关键验收场景

1. 全新用户，无需登录即可看到第一条短句并播放示范。
2. 第一次拒绝麦克风时仍可听示范、换句、收藏。
3. 用户录音三次后可回放最新一次，不会错误播放上一句。
4. 正在播放英语示范时切换句子，旧音频及时停止。
5. 退出并重启后，历史和收藏仍然存在。
6. 只浏览五句不应该显示“已掌握五句”。
7. 触控板与鼠标/键盘均能完成首版必要操作；V1.0 再增加沉浸滑动。
8. V1.0 内部测试只朗读半句时，不会自动绿完整句。
9. V1.0 自动接话关闭时，系统不主动出声；开启时不能抢在用户说话过程中提示。
10. 发音评估未启用时，UI 不显示确定性红色音素错误。

## 9. 不做功能（本轮冻结）

无账户、无会员、无 AI 自由聊天、无实时识别、无自动接话、无无限刷句信息流、无音素打分、无内容社区、无考试证书、无复杂图表。
