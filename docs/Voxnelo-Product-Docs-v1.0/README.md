# Voxnelo（中文名候选：声语跃动）｜产品文档包

**版本**：Product Baseline 1.0｜**日期**：2026-10-15｜**状态**：需求基线冻结，可进入 V0.1 开发。

> **品牌说明**：`Voxnelo` 与“声语跃动”均为工作候选名称，**未完成商标、域名及应用商店正式核验**。对外上线前必须完成名称确认。之前的 `SpeakSeed` 是历史项目代号，不再作为首选品牌。

## 一句话定义

先做一款对中文英语零基础用户真正有用的、免费的**桌面英语跟读工具**；在后续正式版本里推出三大特色：**SpeakFeed（沉浸式刷句）+ Speak Karaoke（随用户声音实时点亮）+ Smart Prompt（可开关自动接话）**；长期扩展到移动端与外国人学中文。

## 版本约定

- **V0.1 Early Access（先发布）**：桌面端优先。播放/慢速听音、录音回听、换一句、历史、收藏、基础复习。**不用 AI、没有实时识别、没有上下滑动信息流**。
- **V0.2–V0.3**：分段跟读、中文指导、复习、基础推荐，稳定基础体验。
- **V0.9 Internal**：内部测试三大特色功能，不公开承诺。
- **V1.0 正式上线**：在质量达标前提下公布三大特色；音素级精准标红未通过验证则推迟，不得假装已实现。
- **移动端与双向语言**：长期必达方向，但不拖慢桌面首发；从架构上预留，按独立课程与模型实施。
