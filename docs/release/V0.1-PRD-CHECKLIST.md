| 编号 | PRD 功能 | 当前实现与验证边界 | V0.1 放行前检查 |
| --- | --- | --- | --- |

| F002 | 单句英语/中文、音标、难度/场景 | 40 句、React 练习卡和场景标签、音标折叠 | 母语者复核译文、IPA 与长句可读性 |

| F004 | 权限、录音、停止、回听 | MediaRecorder + 临时 Blob URL，支持权限错误与播放；已配置组件/假设备自动化测试 | 真麦克风、三次重录、设备拔出、暂停/休眠和系统权限拒绝实测 |

| F008 | 需要复习标记 | 本地人工标记；不声称算法判断发音正确 | 真实学习者能返回薄弱句 |

| F012 | 无障碍 | 键盘、焦点、减少动效、窗口响应式自动化 | Windows/macOS/Linux 实机及放大/屏幕阅读器基本操作 |

## 严格不属于 V0.1 阻断项

- **不做**：AI 自由对话、语音识别、音素评分、实时 Kara​oke 高亮、Smart Prompt、上下滑动 SpeakFeed、云账户、付费服务。
- PR #35 是用于未来 V0.9/V1.0 的**实验性 ASR 开发分支**，不应抢占本版 F001–F012 开发，也不应合入 V0.1 主分支。
- 不能因为 Electron 虚拟显示器 CI 全绿就宣称实机麦克风通过；不因 40 句存在就宣称专业内容审核完成。

## Gate B 发布阻断清单

- [ ] 指定首发桌面系统，在真实麦克风上完成「听示范 → 录音 → 停止 → 回听 → 换句 → 历史」全程。
- [ ] 明确关键英语发音素材/系统 TTS 的合法分发边界及质量限制，完成课程译文和音标审核。
- [ ] 在目标机器验证系统权限拒绝、麦克风断开、三次重录、窗口重启后的收藏/历史持久化。
- [ ] 至少 **5 名英语初学者**独立体验完成任务，并记录和修复阻断性问题。
- [ ] README/发布文案写清楚「不提供实时识别或自动发音纠错」，核实隐私声明。
- [ ] 品牌名称、应用分发授权、包签名/目标平台实机验证达标后才发布 v0.1.0。
