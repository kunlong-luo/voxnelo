## Scoped online registry measurement

Run the existing supply-chain audit on a change to its own workflow or named integrity scripts/lockfile, on its existing schedule or by manual dispatch. The JavaScript job retains high/critical production and full-tree advisory checks, then performs a frozen install, builds all three inventories and explicitly calls:

```sh
pnpm license:audit:registry
```

The job publishes only the dedicated sanitized archive integrity report (public dependency name/version, expected/measured digests, byte counts and lockfile SHA-256), not installed raw inventories, source paths, full license text, package archives or private files. Artifact retention is 14 days. It is review-only and does not change the ordinary PR aggregate gate, app runtime, lockfile, model version or publication settings. Review source/run identity, verify all measured hashes and compare with the exact frozen lockfile before assigning additional points. CI and actual archive measurements are pending at submission.
