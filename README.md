# Voxnelo

**从第一句开始，自信开口。**

Voxnelo 是免费、无须注册、本地优先的英语短句跟读练习桌面应用。

**当前源码版本：0.1.5 · Early Access（测试阶段）**  
**开发者：Leo Luo** · [MIT 许可证](LICENSE)

> 本 README 只介绍 **0.1.5 已实现的功能**。代码和自动化构建已通过检查，但各平台真实设备、首批内容与授权尚未完成全部发布验收，不能把构建成功当成正式稳定版。

## 0.1.5 可以做什么

- **短句学习**：内置 40 条日常英语短句，展示英文、中文释义、场景、难度和可开关的 IPA 音标。
- **听示范**：调用本机系统英语语音（TTS）朗读，提供正常/慢速播放与重播；实际可用声音取决于操作系统语音包，不是专业母语者录音。
- **跟读与回听**：主动授权麦克风后录音、停止并播放本次练习的录音；切换句子后不保留旧录音。
- **自由换句**：上一句/下一句和课程目录入口，无须先完成当前句子。
- **学习记录**：区分浏览和实际练习，提供历史、收藏和待复习标记；学习状态保存在当前设备的 IndexedDB 中。
- **内容浏览**：按场景查看短句，浏览历史与收藏，并在相关列表中搜索、筛选。
- **界面与设置**：简体中文/英文（跟随系统或手动选择）、北欧极简与暖色日落双主题、慢速朗读、音标显示及减少动效设置。

**离线与隐私**：基础课程与学习记录无需登录或云端账号；Voxnelo 不提供自己的音频上传服务。原始跟读录音仅供本次临时回听，默认不持久化。参考朗读依赖设备可用的系统语音引擎，不能保证所有系统均离线可播。

### 实时听写（仅实验性、需自行配置）

0.1.5 包含**本地实时听写的实验性入口和会话代码**，但公开的标准安装包**不附带第三方离线 ASR 模型或原生识别库**。只有在受支持的 Linux x64 环境中，用户主动安装并通过完整性校验的个人内测引擎后，才可能启用本地英语听写；识别准确率、持续稳定性和降噪效果尚未通过实机发布验收。

不安装该引擎也可以正常使用听示范、录音回听、收藏和学习历史。具体限制及个人测试说明见 [个人离线 ASR 内测说明](docs/engineering/LOCAL-ASR-PERSONAL-PILOT.md)。

## 安装与体验

目前尚**未创建正式的 GitHub Release**。如需试用，请使用经过 CI 构建的测试安装包：

- **Linux（Debian/Ubuntu/Pop!_OS）**：从 [最新 CI 的 Artifacts](https://github.com/kunlong-luo/voxnelo/actions/workflows/ci.yml?query=branch%3Amain) 下载 `voxnelo-linux-pr-installers`。解压后双击 `Voxnelo.deb` 可以让 KDE Discover 的本地文件预览显示正确应用名称；`voxnelo_0.1.5_amd64.deb` 是内容相同的标准版本命名文件。也可使用 `sudo apt install ./voxnelo_0.1.5_amd64.deb` 安装或原位升级，**不需要先卸载旧版**。
- **Linux AppImage**：同一测试构建中提供 `Voxnelo-0.1.5.AppImage`，可用于受支持的 Linux 桌面环境；系统库、权限与桌面集成需按发行版验证。
- **Windows / macOS**：仓库已有打包与内部候选构建流程，但安装器仍属于**未签名/未完成真实设备验收的测试产物**，尚未作为公开 Release 附件发布。

GitHub Actions 测试附件有保存期限，也可能要求登录 GitHub。完整的 [候选安装包与验收说明](docs/engineering/V0.1-RC-PLAYBOOK.md) 说明了如何获取和验证它们。

## 使用方法

1. 打开「练习」，选择短句并点击「播放示范」。
2. 点击跟读录音按钮，允许麦克风使用；再点击停止，回听自己的声音。
3. 切换其他短句，或使用收藏、历史、复习标记继续练习。

**本版本不提供自动发音评分。** 浏览、录音次数和用户自评均不代表系统已经判断发音正确。
